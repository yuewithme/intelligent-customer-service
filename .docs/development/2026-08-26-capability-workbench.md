# 能力工作台只读可视化

## 任务目标

在现有 Vue 管理后台新增只读“能力工作台”，把能力目录和兰花首单经验包转换为业务人员可以理解的可视化页面；同时将项目现役 Git 工作流统一到 GitLab `origin/main`。

本任务不接数据库、不提供拖拽编辑、不改变生产 Agent 和现有 SOP 运行逻辑。

## 实施计划

1. 将 `AGENTS.md` 和 `README.md` 中过期的 Gitea 说明改为 GitLab `origin/main`。
2. 新增编排领域只读加载服务，使用既有 Pydantic 契约校验能力目录和经验包样板。
3. 新增管理端聚合 API，返回能力统计、能力清单、经验包图结构和引用关系。
4. 在 Vue 管理后台新增“能力工作台”菜单、路由、API 类型和页面。
5. 使用原生 Vue、CSS 和 SVG 展示经验包步骤、连线和能力详情，不新增流程图库依赖。
6. 完成针对性后端校验、前端类型检查和生产构建。
7. 检查最终差异和敏感信息，提交并推送 GitLab `origin/main`。

## 完成结果

- 将项目默认 Git 工作流和 README 现役说明统一为 GitLab `origin/main`，本地 `origin` 已指向指定仓库。
- 新增只读编排聚合服务和管理 API，运行时加载并校验能力目录与经验包定义，返回统计、引用关系和完整图结构。
- 管理后台新增“智能编排 / 能力工作台”菜单和 `/operations/capability-workbench` 页面。
- 页面提供“经验包流程”和“能力模块”两个页签：支持流程图、步骤/连线/结果详情、能力筛选、能力详情和引用位置跳转。
- 经验包画布使用原生 Vue、CSS 和 SVG，不新增流程图库依赖。
- 同步文档索引和编排协议，明确只读工作台已实现，数据库、编辑、拖拽、发布和生产运行接入仍未实现。
