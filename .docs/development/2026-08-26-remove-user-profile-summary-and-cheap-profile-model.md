# 删除用户画像摘要并降低画像记忆模型成本

## 任务目标

- 保持主回答模型配置不变。
- 将画像分析与记忆提取共用的 `profile` 模型配置为 `qwen3.7-flash`。
- 删除工作台监督面板中的用户画像卡片。
- 删除重复的 `ai_summary` 生成、传输和消费逻辑，保留客户标签、兴趣、痛点、基础资料、转人工状态和新版记忆事实。

## 实施计划

1. 在生产模型配置与示例配置中明确指定 `profile` 使用 DashScope `qwen3.7-flash`。
2. 删除前端用户画像卡片及其专属字段和计算逻辑。
3. 删除后端 `ai_summary` ORM 字段映射、接口输出、Agent 上下文、Persona/RAG 上下文和评测注入中的重复逻辑；不对线上数据库执行破坏性删列。
4. 更新直接受影响的测试数据与断言。
5. 运行模型路由、用户画像、上下文和工作台前端的最小相关检查，并复核最终差异。

## 完成结果

- 生产环境、示例配置和应用默认配置均将 `profile` 模型指向 DashScope `qwen3.7-flash`；`business` 主回答模型配置保持不变。
- 工作台监督面板已删除用户画像卡片，客户标签页及监督面板顶部标签继续复用原 profile 接口。
- 后端已删除 `ai_summary` ORM 映射、临时摘要拼接、接口输出、Agent/Persona/RAG 重复注入和前端类型字段。
- 线上数据库不执行破坏性删列；历史物理列由旧库自然保留，但应用不再读取或写入。
- 评测专用客户背景改为独立 `customer_context` 传入，不再冒充画像摘要。
- RAG 地区事实校验改为读取结构化 `shipping_city` 和省市标签，避免删除摘要后丢失地区校验能力。
