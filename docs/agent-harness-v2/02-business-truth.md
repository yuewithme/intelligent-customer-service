# 02 业务事实与产品服务

这份文档定义 Agent 可以依赖哪些真实业务信息。具体数据应通过后台、数据库或工具提供，
本文只记录权威来源和解释，不填写密钥或真实客户数据。

## 1. 品牌与经营范围

已确认的品牌名称、主营业务、主要客户和差异化价值：

- 品牌名称：萧岚苑
- 主营业务：兰花商品、兰花养护相关商品，以及以系统资料、视频课程和结合实际情况的一对一指导为核心的陪伴养兰服务。
- 主要客户：以中高龄男性为主，包括刚开始养兰的新手、养护中反复出现问题的兰友、有明确选品需求的客户，以及已经购买后需要持续养护支持的老客户。
- 核心差异化价值：不只完成一次商品交易，而是帮助客户选到更适配的兰花，并在购买后把养护基础和实际问题逐步理顺。
- 暂不经营或不提供的内容：不代客户下单；不由 AI 修改订单、退款、改价或承诺未经核实的赠品、库存、发货与养护效果。

网上和花鸟市场来源的兰花中，品种不对版、温室或激素苗、家庭环境适应性不足、售后缺少持续指导是常见风险，这些方向在相关问题中占比较大。面向某一位客户时，可以表达“可能是、常见于、大概率与这些方向有关”，并结合图片、苗情和养护经历继续判断；不能只凭购买渠道断言客户手上的兰花一定是假苗、激素苗或不对版。

### 全客户、全商品统一风险逆转权益

以下权益适用于所有客户和所有商品，可以作为试成交、价格顾虑、怕养不活和临门促单时的固定风险逆转事实：

- 养不活包补发；
- 可以由兰园寄养一段时间后再发货；
- 固定有赠品。

Agent 可以直接确认上述权益存在，不需要逐商品判断是否支持。当前尚未提供补发的具体条件和次数、寄养的具体时长、赠品的具体名称和数量；这些细节不能自行补充，客户追问时应查询后续补充的政策事实或请人工确认。

## 4. 价格、库存、优惠和活动

以下事实原则已确定：模型不能凭记忆或经验确认动态业务事实，必须以工具结果为准。

每类事实的权威来源和无结果时的处理方式：

| 事实 | 权威来源 | 多来源冲突时以谁为准 | 查询不到时允许怎么说 |
| --- | --- | --- | --- |
| 当前售价 | 有赞在售商品 / 本地同步商品目录 | 以当前交易系统的有效售价为准 | 说明暂时无法确认价格并稍后重查，不引用历史话术价格 |
| 库存 / 是否可售 | 有赞库存与在售状态 | 以当前交易系统为准 | 说明暂时不能确认是否有货，不用“应该有”代替查询 |
| 优惠与活动 | 当前活动库尚未完整，已接入部分以真实活动配置或有赞商品事实为准 | 真实工具结果优先；申请型福利由人工最终确认 | 可以结合语境自由表达“价格已经很实在、可以帮您问问或申请看看”，随后转人工；不得声称已申请成功，也不得编造金额、名额、最低价或截止时间 |
| 赠品 | 全客户统一权益确认“固定有赠品”；具体赠品内容来自当前商品、订单或活动规则 | 赠品存在性以统一权益为准，具体名称和数量以当前有效政策为准 | 可以确认有赠品；具体内容暂时无法确认时不自行填写 |
| 发货时效 | 订单、物流或人工履约信息 | 已生成订单以订单系统为准，未下单以当前政策为准 | 不给未经确认的具体日期 |
| 服务权益 | 当前服务商品与客户真实购买权益 | 订单权益优先于历史话术 | 说明需要进一步核实，不先承诺开通 |

## 6. 专业知识边界

哪些兰花和养护结论可以直接回答，哪些必须先补充图片、环境信息或查询资料，
哪些问题必须转人工专家？

- 可以直接回答：通用且低风险的养护原则、常见观察方法、选品考虑维度、收货后的基础注意方向；表达时保留适用条件。
- 信息不足时应说明不确定并补充：具体病因、用药、是否烂根、是否能恢复、不开花原因、品种识别和环境适配；优先补一项最能改变判断的信息或图片。
- 必须查询资料：特定品种养护手册、商品规格、实时价格库存、服务权益、订单物流、受限课程和资料权限。
- 必须转人工：需要人工看苗、确认品质或授权业务动作。

## 客户等级与购买状态事实

- L1-L6 沿用现有标签目录，但表示可随新证据修正的客户理解，不表示销售流程走到哪一步，也不能直接决定回复或工具。
- 等级综合盆数、养兰时间、问题复杂度和关注点判断；单个品种名、痛点或关键词不能独自决定等级。
- `抖音已购` 只由已支持店铺的订单截图核验写入；`微信已购` 只由当前客户真实已付款的微信 / 有赞订单写入。客户口头说“买过”只触发核验，不直接形成已购事实。
- 两个已购标签可以同时存在；任一真实已购标签成立后，优先承接订单、养护和长期服务，同时仍可识别复购需求。
| 商品卡片 | 可进入有赞小程序查看和下单的真实商品入口 | 自行拼接商品链接 | 通过商品查询返回的真实引用发送卡片 |
| 会员 / 首单体验 | 历史和当前服务中的业务称呼 | 把全客户固定享有的包补发、可寄养和有赠品误解为只有历史会员才有，或继承历史案例中的具体细节 | 面向客户可确认三项统一权益；具体价格、补发条件、寄养时长和赠品内容以当前事实为准 |
