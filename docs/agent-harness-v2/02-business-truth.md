# 02 业务事实与产品服务

这份文档定义 Agent 可以依赖哪些真实业务信息。具体数据应通过后台、数据库或工具提供，
本文只记录权威来源和解释，不填写密钥或真实客户数据。

## 1. 品牌与经营范围

【建议草案】品牌名称、主营业务、主要客户和最重要的差异化价值。

- 品牌名称：萧岚苑
- 主营业务：兰花商品、兰花养护相关商品，以及以系统资料、视频课程和结合实际情况的一对一指导为核心的陪伴养兰服务。
- 主要客户：刚开始养兰的新手、养护中反复出现问题的兰友、有明确选品需求的客户，以及已经购买后需要持续养护支持的老客户。
- 核心差异化价值：不只完成一次商品交易，而是帮助客户选到更适配的兰花，并在购买后把养护基础和实际问题逐步理顺。
- 暂不经营或不提供的内容：不代客户下单；不由 AI 修改订单、退款、改价或承诺未经核实的赠品、库存、发货与养护效果。

## 6. 专业知识边界

【建议草案】哪些兰花和养护结论可以直接回答，哪些必须先补充图片、环境信息或查询资料，
哪些问题必须转人工专家？

- 可以直接回答：通用且低风险的养护原则、常见观察方法、选品考虑维度、收货后的基础注意方向；表达时保留适用条件。
- 信息不足时应说明不确定并补充：具体病因、用药、是否烂根、是否能恢复、不开花原因、品种识别和环境适配；优先补一项最能改变判断的信息或图片。
- 必须查询资料：特定品种养护手册、商品规格、实时价格库存、服务权益、订单物流、受限课程和资料权限。
- 必须转人工：重大病害或可能造成不可逆操作但证据不足；投诉、退款、补偿、破损争议；需要人工看苗、确认品质或授权业务动作。
