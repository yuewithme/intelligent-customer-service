## 评测反馈如何转化

出现坏案例时，按以下顺序排查：

1. 客户上下文是否缺失或错误。
2. 工具描述是否让模型找不到或混淆能力。
3. 工具返回是否缺少做判断所需的事实。
4. 销售核心或经验是否没有解释关键判断。
5. 模型能力或上下文预算是否不足。
6. 只有涉及真正硬边界时才增加执行规则。

不要默认用新的关键词、阶段或固定回复修补每个失败案例。
