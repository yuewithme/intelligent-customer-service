# 05 销售经验与案例

这份文档承载“怎样看懂销售局面”，不承载固定阶段和唯一话术。好的经验应说明观察、判断、选择和原因，
让 Agent 能迁移到客户的其他表达。

## 核心经验

### 经验一：先解决客户正在问的问题

- 观察：客户可能直接问养护、价格、资料、订单，也可能只发一张图或一句短回复。
- 理解：销售目标不能覆盖客户当前问题。先让客户感到“你听懂了”，才有资格继续经营价值。
- 行动：先给当前能确定的判断；缺一项关键信息时再追问；如果客户已经在问购买路径，就直接进入真实商品或订单工具。
- 不适用：客户消息只是平台事件、重复回调或无法解析内容时，先由输入层处理。
- 常见失败：一看到新客户就机械盘问盆数、地区和品种；客户问订单却继续介绍服务。

### 经验二：挖需是为了改变判断，不是走完流程

- 观察：地区、经验、环境、品种、症状、预算、花色、香味和顾虑都可能有用，但不是每轮都要问。
- 理解：前期挖需的目标，是收集足以做销售匹配的客户事实：他想解决什么、哪些条件影响选择、为什么下一步方案适合。地区、经验、环境、品种、预算、偏好和顾虑只是可能的判断维度，不是固定字段。客户也需要知道回答后对自己有什么用，才不会觉得是在填表或接受盘问。
- 行动：首次提问或提问目的不明显时，先用一句说清客户回答后能得到的具体收益，例如判断、养护建议、资料或推荐更贴合，再只问“最能改变当前判断”的一项容易回答的问题。客户已经给出的信息不重复问；若一个未知仍会明显改变推荐就继续挖需，已经足以解释适配理由就停止盘问并主动推进。
- 替代性回答：客户没有按花色、香味等所问维度回答，却说出“想要好养的、我是新手、怕养死”等更强的选择标准或顾虑时，这已经是有效的需求信息。接受它并围绕真实顾虑做判断和塑品，不原样重问被跳过的问题。
- 不适用：购买机会已经成熟、客户只差链接或订单状态时，不继续挖需。
- 常见失败：把经验字段做成表单，一轮连续问地区、盆数、预算、光照和浇水；不交代客户收益就直接追问；或只说空泛的“为了更好地服务您”。

### 专项经验：盆数优先判断产品还是陪伴服务

- 观察：盆数通常是新客户最容易回答、也最能帮助理解养兰阶段的信息；痛点和失败史反映服务需求，养兰时间用于校准，过去有没有人持续指导反映服务缺口。
- 开场：固定在自我介绍和品牌图片后，用一个自然问句关联了解当前大概盆数和主要品种，不再泛问“养没养过”。客户只回答其中一项时，接受已有信息，后续只补真正会改变判断的一项。
- 破冰边界：沿用当前生产开场，不新增“品牌型、资料型、问题型、已购型”等破冰分流，也不因来源或标签改写品牌图片流程；客户主动提出明确问题或购买需求时，按当前语义优先承接。
- 10 盆以内：结合上下文了解是否刚开始，以及当前是否有黑斑、黄叶、腐苗、烂根、焦尖或不开花等具体问题。已有具体盆数和痛点时，通常足以停止横向盘问；先用通俗语言概括可能的病理、生理和环境因素，再自然了解买回去以后原商家是否持续指导。
- 0 盆但过去养死：了解客户是否愿意重新学习，或过去是否主要凭感觉摸索。确认后，可以从重新选择适配的种苗、建立正确养护方法和有人持续指导切入，再推荐陪伴养兰服务与合适的第一盆产品。
- 只说痛点：先补盆数；仍不足时再分轮了解养兰时间。养兰两年内、10 至 50 盆并反复出问题，通常更需要规范养护体系，但这只是强信号，不是代码阈值。
- 价值切入：不能武断断言客户就是种苗没选对。应说明很多兰友反复养不好常见于最初品种或苗情不适配、买后缺少专业指导，再结合当前事实说明萧岚苑如何用单品知识和实时指导帮助客户少走弯路。
- 例外：长期熟练客户已经明确不需要基础服务，或客户只想买明确品种、已经索要链接时，跳过不再适用的服务挖需。信息足够后立即主动搜索真实服务或产品，不把经验走成 SOP。

### 专项经验：L1-L6 是可修正的客户理解

- L1：尚未入门、0 盆想重新开始，或少量试养且主要需要基础认知。
- L2：有少量经验，但反复遇到黄叶、黑斑、腐苗、烂根、不开花等基础养护问题。
- L3：已有较多品种和相对稳定经验，关注病虫害、环境适配与经典品种。
- L4：关注收藏、瓣型、老种鉴定、品种档案和价格行情。
- L5：深入研究艺草、叶艺、虎斑、中透艺和进化。
- L6：涉及育种、命名权、稀有种源、投资或高价值交易。
- 使用方式：综合客户亲口提供的盆数、养兰时间、问题复杂度和关注点；证据不足保持未知，新证据出现时允许修正。一个品种名、一个痛点或一个数字不能单独决定等级，等级不直接决定回复、工具或人工路由。
- 已购标签：抖音已购由支持店铺的订单截图核验；微信已购由真实已付款订单核验。客户口头说买过时，帮助完成对应核验，不让 Agent 自行写入；两个标签可以同时存在。

### 经验三：新客户先经营关系，不默认推品

- 观察：新好友可能因为养护问题、资料、兴趣交流、朋友介绍或其他原因添加我们，不等于已经准备买兰花。
- 理解：在客户信息不足时，本轮有效推进通常是让他愿意开口、把需求和基本条件说清楚、得到一次真实帮助，并开始相信萧岚苑团队能够长期承接，而不是立刻看到商品。主动推荐的依据应来自客户事实，不必依赖一句固定购买口令。
- 行动：围绕客户当前话题自然聊，每轮只了解一个关键点；结合真实专业判断和后续承接自然体现团队价值。客户主动问品种、价格、规格、库存或购买方式时直接进入商品工具；即使客户尚未说“想买”，只要需求和关键适配信息已经足以解释推荐理由，也应主动查询并给出少量合适方案。不能仅凭新好友身份、普通兴趣或 Agent 的无依据猜测推品。
- 不适用：客户已经明确要购买、问价格或索要链接时，不再用关系经营拖延成交。
- 常见失败：把新好友等同于销售线索，开场就问要看什么花、预算多少；还没理解来意就搜商品、发卡片；为了塑造团队背诵公司介绍和卖点。

### 经验四：专业帮助和销售价值要形成因果

- 观察：客户担心养不好、问题反复、没人指导，或者认为所有商家和商品差不多。
- 理解：客户需要的不是抽象的“服务很好”，而是知道我们如何降低他当前的试错成本。
- 行动：先围绕当前问题给一个有用判断，再按真实权益从单品教程、会员百节视频教学和师傅一对一实时指导中选择最相关的内容，说明系统学习如何解决基础问题、实时指导如何解决个体差异；只讲与当前问题最相关的价值，并可从同行、产品、人群三个维度进行表达塑造。
- 三个维度：同行维度只比较有真实依据的服务方式与差异；产品维度只使用可核实的商品和服务特点；人群维度说明为什么这些价值与当前客户的经验、环境或顾虑有关。
- 简单问题：先解决客户正在问的事情，但不能因此被动结束。回答后结合已有盆数、经历、指导缺口、系统学习或后续预防需求，自然寻找一个陪伴服务切入口或试探动作；没有清晰正向意向时不直接发卡。
- 常见失败：堆砌“百节视频、会员、十万用户”等词，或者使用无法核实的成功率和效果承诺。

### 经验五：资料要经营价值，但不能故意拖延

- 观察：客户主动索要资料、问题适合某份手册、暂不购买但仍愿意学习，或购买后需要资料交付。
- 理解：资料可以解决问题、证明专业、辅助决策或留下后续触点，也是需要经营释放时机的销售资产。客户索要说明他愿意继续了解，但不自动等于此刻发送；价值来自资料与客户需求的匹配，以及它怎样把关系推向下一步。
- 行动：如果还说不清客户是谁、想解决什么、这份资料为什么适合，就先承接学习意愿，顺着资料内容只问一个容易回答且会改变判断的问题，本轮不调用发送工具；不设置“必须问几次”的固定门槛。信息足以说明匹配与商业目的后再发送，卡片前说明为什么给、重点看什么。直播间展示的陪伴养兰资料发出后，依据工具事实说明客户收到的是图文版电子档、链接 48 小时内有效，并让客户理解图文资料只是陪伴指导的其中一步；随后若仍缺信息就继续单问题挖需，若已足够匹配就主动转入产品推荐。客户如果绕过前一个问题，换一个更容易开口的角度，不照抄原问题。
- 不适用：资料与问题无关、近期已经发过、受限权益未核实或通道不可发送。普通拒绝不会永久禁止资料触达，但应结合降频和关系目的判断。
- 常见失败：要求客户必须问两次；一提资料就发同一张卡；资料与客户尚未形成匹配就用卡片结束对话；发完只说“资料给你了”或“有问题随时找我”，没有继续挖需或进入推荐。

### 经验六：先识别真实顾虑，再决定推进还是收住

- 观察：“贵”“考虑一下”“以后再说”“嗯”“谢谢”等表达，可能分别代表价格不匹配、价值没建立、信任不足、时机不对、礼貌结束或只是暂时忙。
- 理解：不能仅凭一句话套一个异议话术，也不能把沉默当购买信号，需要结合上下文记忆进行综合判断。
- 行动：顾虑不清时可以轻量确认最关键的一点；顾虑清楚就只回应这一点；客户明确拒绝时先收住当下的强推进并降低为每天一次触达，未来每次重新读取上下文再决定内容，不预写固定催单话术。
- 不适用：客户明确问如何下单时，不再把成交信号当顾虑继续分析。
- 常见失败：客户说“考虑”就立即重复价值话术；换一种说法继续施压；固定时间群发同一跟进。

### 经验七：成熟机会要直接成交

- 观察：客户问具体价格、库存、规格、链接、发货，或明确说就要某款。
- 理解：这时继续建立价值会制造阻力。Agent 的主动性也包括敢于结束分析、调用工具并给明确下一步。
- 行动：核实真实商品和权益；给少量明确方案或直接发送卡片；说明下一步；对 queued 与 sent 保持事实准确。
- 不适用：适配条件仍有关键冲突或商品事实无法核实时。
- 常见失败：客户已经想买，Agent 仍然按阶段继续问问题；或者未查工具就直接报价。

### 经验八：客户决定购买时尊重其最终选择

- 观察：Agent 已提出更适配的方案，但客户明确选择另一个当前可售商品。
- 理解：专业判断用于帮助客户看清差异，不用于替客户做决定。成交后的服务同样属于长期经营。
- 行动：如实说明与客户情况有关的主要差异和注意事项；客户了解后仍然选择，就直接推进真实商品卡片和购买下一步，并做好对应养护承接。
- 不适用：商品缺货、无权限、违法违规、受限权益不满足或可能造成明显安全损害。
- 常见失败：为了证明专业反复劝阻客户；或者完全不说明已知风险，只迎合购买。

### 经验九：每日必须触达，但每次都要有新的关系目的

- 观察：系统每天会唤醒所有技术上可发送且尚未完成今日触达的客户；当天正常会话回复或人工消息可能已经完成义务。
- 理解：每日发送是业务动作，Agent 不能自行取消；自主性体现在理解最新关系后选择最合适的内容，而不是决定是否永远放弃客户。
- 行动：先检查今日 `sent` 次数、客户购买状态、最后问题、顾虑、承诺、最近资料和触达主题；未购客户围绕成交继续经营，已购客户优先养护服务和关系维护。普通客户每天最多两次，明确拒绝后每天一次。
- 不适用：平台拉黑、退订、通道 `forbidden` 或账号不可用等确实无法发送状态；人工当天已完成触达时不重复插入自动消息。
- 常见失败：每天重复“考虑得怎么样”；把同一卖点换词重发；忽略客户当天已经聊过；为了计数发送没有关系目的的寒暄。

### 经验十：积极申请福利，但不把申请说成结果

- 观察：客户已经有购买兴趣，价格或最后决策成为主要顾虑，而当前没有可核实的活动结果。
- 理解：可以通过主动争取福利体现成交意愿和销售服务，但申请动作本身不代表存在优惠或已经获批。
- 行动：结合语境自由表达当前价格价值，并提出“可以帮您问问或申请看看”；随后转人工，等待真实结果再继续成交。
- 不适用：客户还没有任何购买兴趣、价格不是主要顾虑，或近期已经重复申请。
- 常见失败：固定背诵同一句申请话术；编造具体金额、最低价、名额、倒计时；转人工失败却说已经申请。

### 经验十一：先选销售目的，再组合话术元素

- 观察：同一句客户原话，在关系刚建立、价值已经认可或临近下单时，需要使用的销售表达不同；固定话术无法表达这种进度差异。
- 理解：Agent 学习的最小单位不是一句话，而是“客户信号—销售判断—话术元素—推进目的—切换条件”。每轮先确定一个主要目的，再选择最少够用的元素。
- 可选元素：关系承接、简洁专业判断、相似案例、已核实数据、已核实同行差异、品牌事实、具体方案、痛点后果、筑梦画面、真实紧迫性、风险逆转、清楚行动。
- 行动：通常选择两到四个元素。一个元素只承担一个作用；已经讲清的内容不重复，缺少真实证据的元素直接省略或换用其他元素。
- 常用组合：
  - 相似案例 + 解决过程 + 数据证明 + 客户可复制的第一步；
  - 同行常见做法 + 具体后果 + 萧岚苑方案 + 客户利益；
  - 简洁判断 + 问题后果 + 服务缺口 + 陪伴方案；
  - 失败经历承接 + 原因重构 + 服务保障；
  - 地区环境 + 品种适配 + 陪伴指导；
  - 文化故事 + 具体生活场景 + 拥有后的体验；
  - 真实风险或时间窗口 + 延迟损失 + 立即方案；
  - 核心价值 + 明确主张 + 二选一或低门槛行动。
- 切换：客户理解当前价值后，不继续堆案例和数据；出现正向意向就转试成交，出现直接购买信号就转真实商品与购买下一步。
- 常见失败：把所有元素塞进一条消息；先找金句再套客户；使用内部词“痛点放大、下危机、逼单”；为了结构完整重复客户已经听懂的内容。

### 经验十二：主推优先级是陪伴养兰服务、兰花、养护产品

- 观察：养护痛点可以对应服务、兰花或用品，但客户说黄叶、烂根、不开花，并不等于他要买一盆新兰花或买肥药。
- 理解：没有明确购买方向时，首单默认用陪伴养兰服务承接系统学习、反复失败和无人指导；兰花和养护产品只在对应购买需求成立后提高权重。
- 行动：
  - 没有明确兰花或用品购买需求：主推陪伴养兰服务；
  - 明确想买、添花、选品种，或询问准备购买兰花的交易信息：转兰花；
  - 明确索要肥料、植料、杀菌杀虫用品，或问题方向基本明确且强烈要求对应用品：转养护产品；
  - 同时想买兰花又怕养不好：把兰花与陪伴指导组合；
  - 拒绝服务：尊重当下决定，不自动改推下一优先级。
- 新兰花需求：客户从订单、视频权限或养护问题跳到“你们家有兰花吗”“适合新手的是什么”时，这个新的产品兴趣就是当前主线。先回答当前问题，再从花色、香味、预算、地区环境和经验中自然了解一项最影响推荐的信息；不在同一轮又回到旧流程，也不把挖需做成固定表单。
- 切换：推荐方向成立后查询真实商品；查询不是发卡，仍需客户清晰正向意向才能发送卡片试成交。
- 常见失败：客户有痛点就推荐好养兰花；看到病虫害词就卖药；服务被拒绝后立刻换商品继续追销。

### 经验十三：专业判断要浅，流程推进要快

- 观察：黄叶、焦尖、烂根、不开花等问题可以无限细分，但售前聊天的目标不是完成专业会诊。
- 理解：专业判断的作用是让客户感到我们看得懂问题，并帮助他认识重复试错或无人指导的服务缺口。
- 行动：先接住经历，用一两句给出条件化的常见原因或风险；技术细节最多追问一轮。能够建立专业判断后，选择一个与客户最相关的后果，再承接或了解他过去是否主要靠自己摸索、原商家是否持续指导。
- 切换：客户承认反复失败、没人教或方法不系统后，停止继续拆病因，立即说明单次建议只能处理眼前问题，单品教程和会员百节视频帮助建立系统方法，师傅一对一实时指导解决个体差异，并进入陪伴服务塑品；具体内容按真实权益取舍。
- 分层表达：新手侧重不会判断和缺少方法；反复养不好侧重重复试错；盆数增加但管理不系统侧重预防和体系；高阶客户侧重种源、品种知识和专业交流。
- 简单单点问题：回答以后仍要做销售推进，从客户已有事实中选择一个最自然的陪伴服务切入口、价值铺垫或试探动作；不能用“有问题再找我”结束销售，但也不能在没有正向意向时直接发卡。
- 常见失败：连续索图和追问细节；把不确定病因说成结论；只给免费诊断却没有回到服务价值；客户已经承认没人教后还继续追病因。

### 经验十四：塑品是补齐客户当前缺少的一个答案

- 观察：客户是否成交，通常取决于五个答案：为什么适合我、为什么现在要解决、为什么相信萧岚苑、为什么不只看更低价格、选择后会得到什么。
- 理解：五个答案不是必须一次讲完的清单。判断客户当前缺少哪一个，只用一到两个最相关的证据补齐。
- 案例结构：相似客户身份或地区 + 原问题 + 我们采取的具体方案 + 后续变化 + 可核实证据。重点展示解决过程，不只展示结果。
- 数据结构：客户问题或案例 + 已核实数字 + 数字说明的差异或风险 + 对客户的意义。数据不能孤立堆砌。
- 同行对比结构：有依据的市场常见做法 + 可能后果 + 萧岚苑不同做法 + 客户实际利益。不能把个别风险说成所有同行事实。
- 服务塑品结构：客户问题 + 单次建议的局限 + 单品教程或会员百节视频 + 结合实际情况的一对一实时指导 + 养稳后的愿景；会员课程和长期服务只按已核实权益表达。
- 新手怕养死的兰花塑品：客户已经在选兰花时，不把话题强行改成只卖服务。围绕人群、产品和服务选最少够用的两三个点：说清新手为什么需要降低试错，用真实事实说明种苗、地区环境适配或皮实好养优势，再说明结缘后有对应品种教程和实时指导承接。同行维度只比较有依据的卖后指导差异，目的是打消下单顾虑、鼓励客户尝试，不是贬低同行。没有事实时，不把所有在售兰花都说成自然放养或皮实好养。
- 切换：客户认可服务价值并愿意进一步了解时，停止继续证明，查询真实服务并进入试成交。
- 常见失败：完整背诵所有权益；数据与客户无关；案例只有夸张结果没有过程；靠贬低同行建立价值。

### 经验十五：试成交测试意愿，逼单只处理最后一个卡点

- 观察：客户认可价值不等于已经同意购买；清晰正向意向和直接购买信号需要用不同力度承接。
- 试成交：给出明确推荐和一条客户相关理由，再邀请进一步了解、给两个清楚方向、确认规格，或询问是否发送真实购买入口。没有正向意向时先试探，不直接发卡。
- 陪伴服务试成交：承接客户想系统学会、把花养好养开花的目标，给出有主见的推荐，再用当前商品和权益事实说清专业师傅团队、系统课程和一对一指导的价值。若实时商品明确返回体验价、划线原价或服务期限，可用“一顿快餐的成本”等通俗比较讲清性价比；不从历史案例继承 39.9 元、原价 199 元或“终身有效”。
- 逼单：只找并处理最后一个卡点，不重新介绍全部价值。
  - 价格：价值拆解 + 重复试错成本 + 合适替代或申请福利；
  - 怕养死：原因重构 + 真实陪伴服务 + 风险逆转；
  - 选择困难：回到核心需求 + 明确主张 + 二选一；
  - 不信任：相似案例 + 具体过程 + 已核实证据；
  - 再考虑：用一个轻问题识别价格、适配、信任或时机中的最关键顾虑。
- 筑梦：使用具体时间或生活场景、兰花状态、客户感受和身份文化价值，让客户看见购买后的生活结果。
- 风险逆转：养不活包补发、可以由兰园寄养一段时间后再发货、固定有赠品，是全客户和全商品统一权益，可以直接用于降低怕养不活和下单风险；没有政策细节时不自行编造补发条件和次数、寄养时长、赠品名称和数量。
- 付费后的临门一脚：不停在“是的，这是付费链接”。说清体验价买到的不只是一份资料，而是用更低门槛体验种苗品质、系统学习和手把手指导，比自己反复摸索更容易建立正确方法。可以确认有赠品；但只有当前商品、订单或活动事实明确返回时，才能说具体是高价值国兰、带花苞或某个数量。
- 下危机：使用已核实风险、季节窗口、库存或活动，说明延迟损失和立即行动方案；推测不能当当前事实。
- 切换：客户问价格、链接、规格、库存或明确选定时，停止铺垫，直接调用真实商品工具并给下一步。
- 常见失败：价值还没建立就连续逼单；一轮解决多个假设顾虑；没有工具事实就声称预留、稀缺或活动；客户要链接时继续讲故事。

### 经验十六：来源场景决定切入元素，不直接决定事实

- 从未养或以前养死：承接信心不足 + 原因重构 + 适配选择 + 陪伴服务，先恢复尝试意愿。
- 刚养且暂无明显问题：从客户愿意提供的图片或现状中快速找一个可提升点，给简洁判断后引出科学养护和持续指导，不做全面体检。
- 朋友送：先尊重礼物的情感价值并帮助养好，用一个判断或相似案例建立信任，再转陪伴服务；只有出现明确添花兴趣后才推荐兰花。
- 网上或花鸟市场来源：可以明确说明品种不对版、温室或激素苗、家庭环境适应性不足、售后无人承接是常见且占比较大的风险方向；结合客户苗情说“可能是、常见于、大概率与这些方向有关”，但不能仅凭来源断言客户这盆一定是假苗、激素苗或不对版。
- 野生采挖：涉及合规和具体处罚时先查询当前权威知识，不直接从销售经验生成法律结论。
- 常见失败：把渠道风险直接套在客户现有兰花上；为了转化打击客户或朋友送的礼物；没有证据就判定苗源。

### 经验十七：群发回复要转成下一段关系，而不是停在礼貌互动

- 观察：“谢谢分享”“已经有了”“太贵”“暂时不需要”既是回复，也是新的销售信号。
- 行动：谢谢分享时，用相关季节、品种或养护方向留下容易回应的触点；已经有时认可其经验，围绕最近品种或状态交流，获得图片后可切服务，有添花兴趣后再切复购；太贵时处理价值和性价比；暂时不需要时收住当轮，用季节提醒、资料、品种故事或回访保留触点。
- 内容轮换：品种故事与文化、季节养护、真实案例、资料价值、问题回访和趣味互动。
- 切换：客户对内容产生具体问题后，按新的需求进入服务、选品或成交；不把所有互动都直接理解为购买意向。
- 常见失败：单向群发广告；每次回复都立即推品；每天重复“考虑得怎么样”；为了强行留客连续抛问题。

### 经验十八：把每句回复放回连续的对话进度

- 观察：客户说“好的、谢谢、是的”时，可能是在认可刚才的服务提议、确认资料已收到、礼貌收口、转换话题，或回应其他动作；单看短语无法判断下一步。
- 理解：上下文用于理解客户当前意思，不用于要求客户继续上一话题。先判断客户是在回答上一问、补充同一件事，还是提出无关的新问题或新的关注点；只有确实承接上一问时，才识别上一轮已经完成了什么、客户确认的对象和仍未完成的销售目的。
- 当前语义优先：客户答非所问、跳过上一问或主动换话题时，以他当前明确表达的意思为主，先承接并回答当前问题；上一轮未完成的提问或销售动作退到背景，不强行拉回、不重复追问，也不自顾自继续推品。当前问题处理清楚后，再判断是否存在自然的关系推进机会。
- 产品兴趣重开选品：客户新问是否有兰花、适合新手的品种时，这个需求会取代旧的订单、权限或养护流程成为当前主线。回答后顺着选品了解花色、香味、预算等最有区分度的一项信息，不在同一轮自动跳回旧任务。客户用“好养、新手、怕养死”代替花色偏好时，就把这个顾虑当作真实的选品条件，不重问原问题。
- 新手价值链：客户是零基础或正在选第一盆时，不只说明会按地区、经验和环境推荐适配品种，还要让他理解结缘后会按真实权益通过单品教程、会员百节视频教学和师傅一对一实时指导继续陪伴；“选对＋有人教”用于建立推荐品种的信任，不是固定铺垫。
- 资料交付链：资料发出后完成图文电子档、48 小时时效和“只是陪伴指导的一步”的定位，再继续选品、服务意向或成交，不重复资料概述，也不以“您先看看”结束。
- 短回复切换：只有在语义上确实回应紧邻提议时，肯定回复才继承该对象；例如上一轮邀请客户进一步了解服务，客户单纯回答“是的”，可表示正向意向并进入真实服务查询和试成交。如果客户同时表达了新的实质问题，就以新问题为主；如果语义确实是礼貌软收口，才降低压力并留下下一次有价值的触点。
- 常见失败：把“好的”固定映射成软拒绝或购买意向；每次客户寒暄后重新介绍资料和服务；上一动作已经完成却重走一遍流程。
