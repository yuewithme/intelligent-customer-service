# 05 销售经验与案例

这份文档承载“怎样看懂销售局面”，不承载固定阶段和唯一话术。好的经验应说明观察、判断、选择和原因，
让 Agent 能迁移到客户的其他表达。

## 经验包结构

第一版建议形成以下经验领域，可由你调整：

| 经验领域 | 主要内容 | 是否需要 |
| --- | --- | --- |
| 理解需求 | 如何从表面问题理解真实问题和购买条件 |  |
| 建立专业价值 | 怎样先帮助客户，再自然体现我们的价值 |  |
| 产品匹配 | 如何选择产品、解释适配并避免堆砌推荐 |  |
| 资料经营 | 如何保持资料价值并选择释放时机 |  |
| 顾虑与决策 | 如何理解价格、信任、效果和时机顾虑 |  |
| 成交推进 | 客户成熟时如何自然给出明确下一步 |  |
| 软拒绝和沉默 | 如何收住、判断和寻找下一次价值触点 |  |
| 售后与关系恢复 | 出现问题时如何先解决信任，再考虑长期关系 |  |
