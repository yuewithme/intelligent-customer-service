# 私域销售经验装配决策记录

这份清单记录《私域销售实操经验提炼（Agent 学习审核稿）》与当前 Agent 业务事实、工具事实或硬边界存在冲突的内容。

本轮识别出的事项均已由业务方确认。第 1、2、3、6 项已按最终业务口径装配；第 4、5 项确认采用建议口径；第 7 项确认保持现有破冰模式。

## 1. 审核稿中的企业、效果和风险数据直接作为回复事实

- 状态：已确认并装配。
- 审核稿方向：允许使用 20 余年、200 亩、2 千多个品种、年培育 30 万株、服务人数、效果比例、感染率、复花率和抗性倍数等真实数据。
- 最终处理：已逐项写入业务事实，并由 `brand.service_facts` 返回给 Agent。效果比例作为已核实的历史验证或客户反馈使用，不等同于对单个客户承诺相同结果。

## 2. 补发、寄养、赠品等风险逆转默认可承诺

- 状态：已确认是全客户、全商品统一权益，并完成装配。
- 审核稿方向：风险逆转可以使用补发、寄养、赠品和服务政策。
- 最终处理：养不活包补发、可以由兰园寄养一段时间后再发货、固定有赠品，适用于所有客户和所有商品。Agent 可以直接确认三项权益存在并用于风险逆转；在业务方补充详细规则前，不自行编造补发条件和次数、寄养具体时长、赠品名称和数量。

## 3. 根据购买渠道直接判定激素苗、假苗或不对版

- 状态：已确认并装配。
- 审核稿方向：网上和花鸟市场来源场景可以通过不对版、激素苗、苗质参差等风险推进转化。
- 当前冲突：现有 `brand.service_facts` 只允许说明市面上“有些”商家缺少持续养护承接，不能把所有同行或某个来源直接判定为苗不好；具体苗情也需要证据。
- 最终处理：允许明确说明不对版、温室或激素苗、适应性不足和售后缺失是网上、花鸟市场来源中常见且占比较大的风险方向；可以说“可能是、常见于、大概率与这些方向有关”，但不能只凭来源断言客户这盆一定如此。

## 4. 野生兰花采挖的具体处罚和价值结论

- 状态：已确认按建议处理。
- 审核稿方向：使用“国家二级保护植物、进局两年起”和野生草不开花、价值不高等结论下危机。
- 当前冲突：现有业务事实和知识工具没有将具体法律处罚作为稳定销售事实；法律结论具有时间和情境依赖。
- 本轮处理：运行时经验只保留“涉及合规与具体处罚时先查询当前权威知识”，不装配具体年限和处罚结论。
- 处理口径：可以强调野生兰花受保护、随意采挖存在违法风险；具体判罚年限按当前法律和案件情节查询，不把“两年起步”作为永远固定的话术。

## 5. 未查询真实状态时使用预留、稀缺、活动和时效促单

- 状态：已确认按建议处理。
- 审核稿方向：逼单可使用预留、带花苗稀缺、限时优惠和活动窗口。
- 当前冲突：现有硬边界要求库存、活动、优惠、赠品、时效和执行结果来自真实工具，不能把销售经验或历史案例当成当前状态。
- 本轮处理：完整保留“下危机和真实稀缺促单”策略，但只有本轮工具已经返回对应事实时才可使用。
- 处理口径：预留、稀缺、优惠和活动都是允许的逼单策略，但只有库存、活动或执行工具返回真实结果后才作为当前事实使用。

## 6. 单点养护问题默认升级为陪伴养兰服务

- 状态：已确认并装配。
- 审核稿方向：养护问题优先判断能否上升为系统养护和持续指导需求。
- 当前冲突点：如果理解成“所有单点问题都必须推服务”，会与现有经验中“简单问题已解决且客户无持续需求时不强行引向服务”冲突。
- 最终处理：销售是主要经营目的。即使只是简单单点问题，也要先回答，再从盆数、经历、指导缺口、系统学习或后续预防中寻找一个陪伴服务切入口、价值铺垫或试探动作，不能被动结束；客户没有清晰正向意向时仍不能直接发卡。

## 7. 破冰话术重新组合

- 审核稿最新决定：破冰按照现有模式，不做更改。
- 本轮处理：没有新增或修改破冰经验、开场结构和品牌图片流程。
- 待决定：无；仅记录本轮有意跳过。
