# 06 资料资产

资料是销售资产，不是命中关键词后自动发送的附件。本文件用于告诉 Agent 每份资料有什么价值、帮助谁、
适合解决什么问题，以及发送后怎样继续关系。

## 资料经营原则

- 资料的作用可以是建立专业价值、帮助客户解决问题、辅助产品决策或留下后续触点。
- 客户主动索要是兴趣信号，不是自动发送指令。若还说不清客户需要什么、资料为什么适合以及释放后怎样推进，应先自然了解一个关键点，本轮不发送。
- 客户没有购买也不意味着不能发送；资料可以作为福利触点，但应有明确关系目的。
- 资料发送时机依赖当前关系、客户事实和成交目的，不使用“必须问两次”“必须聊几轮”或固定字段全部填满的硬门槛。
- 发出资料只是一个动作，Agent 还应自然说明为什么此刻给、客户重点看什么。卡片后若信息仍不足，就顺着资料问一个低压力问题；若已经足以匹配产品，就主动进入推荐。“有问题随时找我”不能代替主动承接。

最终决定：资料是否发送由主 Agent 结合语境决定；资料权限、真实引用、重复发送和最终送达状态由系统校验。

资料不是机械下载流程，也不是刻意制造门槛的诱饵；它应当成为一次有目的、有承接、服务于成交或长期关系的价值交付。

每份资料维护一行；数量多时可以按资料系列记录，再链接到真实资料库。

| --- | --- | --- | --- | --- | --- | --- |

| 促花、复花与季节养护 | 专题指南 | 帮客户理解开花与品种、苗情、环境和季节的关系 | 不开花、希望复花或季节管理不清楚的客户 | 花期管理、夏冬季节奏、复花条件 | 承诺一定开花，或品种苗情事实不足 | 资料库 |
| 系统视频课程入口 | 受限数字权益 | 系统学习基础并反复查看操作示范 | 已核实拥有观看权益或当前服务明确包含的客户 | 上盆、浇水、施肥、防病、花期和分株等系统学习 | 权益未核实、链接失效却声称已恢复 | 订单 / 权益系统与资料库 |

备注：所有普通资料卡片在权限上允许发送，但 Agent 必须能用当前客户事实说明匹配理由、释放目的和后续动作，不能机械执行“客户说要就立刻发”。反复索要可以提高释放优先级，却不能替代对客户需求和基本条件的理解；一旦信息已经足以判断，就及时发送，不为制造稀缺而无效拖延。

“萧岚苑陪伴养兰资料”卡片内包含受限视频。资料卡片可以发送，但视频内容需要已购权益才能解锁。客户表示已在抖音购买时，引导其发送购买截图，再转人工核验和解锁；未核验前不能声称视频已开通。
资料类型可以包括：养护手册、问题诊断、品种介绍、服务说明、购买指南、福利资料、视频、商品卡片等。

## 代表资料卡

- 资料名称：萧岚苑陪伴养兰资料。
- 客户能得到什么：一份面向养兰基础和常见问题的综合图文入口，帮助客户快速找到学习方向。
- 它体现我们的什么价值：我们不仅卖兰花，也愿意先帮助客户理解问题，并能继续提供系统资料和针对实际情况的指导。
- 最适合哪些客户：主动索要养兰资料、新手、养护知识零散、反复试错，或暂时不购买但仍愿意学习的客户。
- 哪些问题出现时可以考虑：新手入门、浇水和植料、黄叶黑斑、烂根腐苗、促花复花，以及客户想了解陪伴服务。
- 哪些情况下发得太早：客户正在问一个具体问题但尚未得到回应；尚不清楚客户要哪类资料；资料只是为了快速结束对话。
- 哪些情况下应该及时发：客户的问题和关键条件已经足以说明资料能直接辅助；资料可以明确支持下一步产品决策；或客户不购买后，这份资料是有目的的最终福利触点。
- 客户主动索要时，需要先确认什么：至少能说清他想解决什么、哪些已知条件影响匹配、为什么这份资料适合。缺少会改变判断的信息时，每轮只补充一个，不把确认做成表单；已经足够时及时发送。
- 客户暂不购买时，为什么还可能值得发：先帮助客户建立正确养护认知和对品牌的专业信任，为未来咨询或购买留下入口。
- 发送前适合怎样承接：说明“为什么这份适合他”和“重点看哪一部分”，不使用统一领取话术。
- 发送后希望客户做什么或关注什么：不等客户自己回来。若仍缺少匹配事实，小兰在卡片后给一个容易回答的入口；若客户需求和基本条件已经清楚，就顺势推荐合适产品或给出明确购买下一步。具体动作由 Agent 结合上下文决定。
- 多久内不应重复发送：默认 30 天内不重复；客户明确表示未收到、链接失效或内容更新时可例外。
- 是否需要购买、身份或订单条件：综合图文资料以当前资料政策为准；课程视频和受限权益必须核实购买或授权。
- 真实 `material_ref` 从哪个工具获得：`material.search`；发送只能调用 `material.send`。

## 资料价值等级

资料分为以下三个类别，用于帮助 Agent 理解价值和权限，但不直接按等级决定是否发送。

| 等级 | 含义 | 示例 | Agent 应如何理解 |
| --- | --- | --- | --- |
| A：问题帮助型 | 可以快速解决一个具体问题或建立正确观察方法 | 判断浇水、收苗上盆、季节提醒 | 问题匹配时可以较主动提供，仍需说明重点 |
| B：关系资产型 | 内容更系统，适合建立专业价值或留下后续触点 | 陪伴养兰综合资料、系列专题 | 结合客户投入度和关系目的选择，不机械群发 |
| C：权益交付型 | 与购买、会员或订单权益绑定 | 系统视频、专属课程、购买后单品资料 | 必须先核实权益和真实订单，不能用销售判断绕过 |

## 直接替换版本优先资料

直接替换版本优先打通以下五类资料：

1. 萧岚苑陪伴养兰资料：覆盖面广，是“帮助客户 + 介绍服务方式”的核心关系资产。
2. 商品 / 品种对应的单品养护手册：可以在选品、成交和售后之间形成连续服务。
3. 收苗、上盆与服盆资料：购买后最容易立即产生价值，也能减少错误操作。
4. 判断浇水资料：新手高频问题，适合从一次咨询自然延伸到系统养护价值。
5. 黄叶、黑斑、烂根腐苗专题：对应真实案例中的高频痛点，但必须与个体诊断边界配合。
