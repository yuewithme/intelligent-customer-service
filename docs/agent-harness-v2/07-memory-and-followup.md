# 07 客户记忆与跟进

客户记忆不是一组销售阶段字段，而是让 Agent 知道这个人发生过什么、当前在意什么、我们承诺过什么，
以及还有什么值得处理。

## 系统强制部分

以下由系统负责，不需要 Agent 自行计算：

- 唤醒任务幂等、持久化、到期触发和取消。
- 退订、人工接管或客户新消息后的任务失效规则。
- 微信通道限速和实际发送排队。
- planned、queued、sent、failed、cancelled 状态记录。
