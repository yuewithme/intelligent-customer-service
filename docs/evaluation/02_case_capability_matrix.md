# 十个案例能力映射矩阵

## 1. 标注说明

本文使用 [AI销售助手能力地图](./02_capability_taxonomy.md) 对第一阶段整理出的全部销售节点进行映射。

- 主能力：该节点最核心的AI任务；
- 辅助能力：完成主任务时同时涉及的能力；
- 阶段：节点在销售流程中的位置；
- 依赖：正确完成节点需要的数据或工具；
- 风险检查：后续评测必须检查的安全边界。

本文只标记能力覆盖，不评价原回答质量。

# 6. 后续差距分析的优先能力簇

第三阶段可按以下能力簇组织比较，不按十个案例机械重复：

1. **接待与探询簇**：U1—U6、Q1—Q5；
2. **病害与养护簇**：K1—K3、K6、K8；
3. **地区与选品簇**：K4、K5、K7；
4. **会员价值与成交簇**：S3—S5、S7、O2、O3；
5. **商品组合与方案调整簇**：S3、S5、S6、O1；
6. **订单履约与售后簇**：O4—O7、S8；
7. **事实与权限边界簇**：G1—G7。

这些能力簇将用于比较：

```text
原销售动作
↕
经过专业和业务核验的理想AI行为
↕
当前AI实际输出
```
