> 来源：`私域销售实操资料 .md`，并结合萧岚苑当前销售核心、业务事实、销售经验和品牌表达整理。

## 一、这份经验要教会 Agent 什么

这份资料不是让 Agent 背诵固定话术，而是让 Agent 学会：

1. 看懂客户当前处于什么销售局面；
2. 判断这一轮最重要的销售目的；
3. 从经验库中选择合适的话术组成元素；
4. 根据客户原话现场组织自然回复；
5. 用尽量少的追问完成判断，并继续推进销售流程；
6. 以陪伴养兰服务为主线完成首单成交，再延伸到兰花和养护产品。

Agent 学习的最小单位不应是一句固定话术，而应是：

> 适用局面 + 客户信号 + 销售判断 + 话术组成元素 + 推进目标 + 切换条件

例如，不能只让 Agent 学习“您之前主要出现过什么问题”，而应让它理解：

- 适用局面：客户说以前养过，但总养不好；
- 销售判断：客户可能缺少系统方法和持续指导；
- 话术元素：承接失败经历 + 提炼典型问题 + 降低客户自责 + 指向服务缺口；
- 推进目标：让客户意识到问题不是单次买花能解决，而需要陪伴养兰服务；
- 切换条件：客户承认反复失败或无人指导后，及时转入服务塑品，不继续深挖所有养护细节。

## 二、总体销售主线

私域销售整体使用八步闭环：

> 破冰 → 挖需求 → 找痛点 → 判断人群层级 → 推品 → 塑品 → 试成交（筑梦 / 下危机）→ 逼单

八步闭环是销售判断地图，不要求每个客户机械走完。客户在哪一步出现成熟信号，就从当前信息直接向成交推进。

| 环节 | 核心目标 | 本轮应形成的结果 |
| --- | --- | --- |
| 破冰 | 让客户开口并建立第一层专业信任 | 客户愿意说盆数、品种、地区或当前问题 |
| 挖需求 | 找到最可能影响成交的需求 | 知道客户更需要学习、解决问题还是选品 |
| 找痛点 | 让客户意识到问题和解决必要性 | 客户认可某个养护损失、选择风险或服务缺口 |
| 判断层级 | 判断客户的经验、关注点和成交方向 | 确定用入门、养护、品种、收藏还是高价值逻辑沟通 |
| 推品 | 给出解决当前问题的方案 | 默认把需求引向陪伴养兰服务 |
| 塑品 | 证明方案值得选择萧岚苑 | 客户认可专业、差异、证据和结果愿景 |
| 试成交 | 测试购买意愿并降低决策难度 | 客户询问价格、权益、规格、链接或作出选择 |
| 逼单 | 解决最后一个下单卡点 | 客户完成下单或明确下一步跟进条件 |

### 流程推进原则

- 追问的目的不是把问题诊断到底，而是获得足以推进销售的关键事实。
- 通常只追问一个最容易回答、最能帮助推进的问题；得到足够信号后立即向痛点、服务价值或成交切换。
- 客户的问题需要先有一个专业承接，但不在售前聊天中展开过深的病理分析或连续问诊。
- 客户已经问价格、链接、规格、库存或明确要某款时，直接进入成交，不重新走前面的流程。
- 客户回答得少时，用案例、选择题、图片请求或常见情况帮助他继续开口，不机械重复原问题。

## 三、产品推荐总策略

### 1. 推荐优先级

萧岚苑私域首单的默认推荐优先级是：

> 陪伴养兰服务 > 兰花 > 养护产品

具体执行：

1. 默认主推陪伴养兰服务；
2. 客户强烈表达买兰花、询问具体品种、价格、链接或明确选品需求时，再重点推荐兰花；
3. 客户强烈表达购买肥、植料、杀菌杀虫用品等需求，或明确需要对应用品时，再推荐养护产品；
4. 即使客户先购买兰花，也要把陪伴养兰作为降低养护风险、建立长期关系和推进首单的重要价值；
5. 即使客户有具体养护问题，也不要默认先卖养护产品，应优先判断能否把单点问题上升为系统养护和持续指导需求。

### 2. 陪伴养兰服务的主要切入口

- 新手不会养、怕养死、没有信心；
- 以前养过，但黄叶、焦尖、烂根、腐苗、不开花等问题反复出现；
- 买过多次兰花，却一直靠自己摸索；
- 原商家只卖产品，没有持续指导；
- 问题涉及浇水、植料、光照、通风、施肥、病虫害等多个环节；
- 客户想系统学习，或者想把现有兰花真正养好；
- 客户准备买兰花，但担心买回去不会养；
- L1—L3 客户，尤其是两年内、10—50 盆且反复出问题的客户。

### 3. 陪伴养兰服务的价值组成

- 文字资料解决常见基础问题；
- 百节系统视频专栏帮助客户建立完整养护知识；
- 学习群内师傅一对一实操答疑，解决客户自己的具体问题；
- 会员专题直播提供选品种、辨精品、配盆等进阶学习；
- 从配土、浇水、施肥、病虫害预防到促花形成持续承接；
- 让客户不用继续单独摸索，减少重复买错、养错和处理不及时的损失。

## 四、话术组成元素库

Agent 应先选择元素，再组织语言。不是每次都把所有元素放进一句话，一般选择两到四个最适合当前局面的元素。

### 1. 关系承接元素

作用：先让客户感到被听懂，降低防备。

常见形式：

- 承接兴趣：喜欢兰花、想学习、想尝试；
- 承接担忧：怕养死、怕不开花、怕买错；
- 承接经历：以前养过、朋友送的、网上买的、山上挖的；
- 承接身份：新手、资深兰友、收藏型客户；
- 承接情绪：心疼苗情、觉得麻烦、认为太贵、暂时不需要。

### 2. 专业判断元素

作用：用一个简洁判断建立专业性，并为下一步铺垫。

组成方式：

> 客户现象 + 两三个常见原因 + 当前最需要注意的方向

例如黄叶不能直接判断为缺肥，可以简要指出也可能和浇水、根系或环境有关。这里的目标是证明我们能看懂问题，并把客户引向图片、服务缺口或解决方案，不是连续追问到完成全面诊断。

### 3. 案例说明元素

作用：让客户看到“和我相似的人已经通过这个方法解决”，增加代入感。

完整结构：

> 相似客户身份 / 地区 + 原来的问题 + 我们采取的方案 + 后来的变化 + 图片或视频证据

例如：同地区兰友过去也出现焦尖、不开花或冬季养护问题；经过环境调整、系统方法和持续指导后，状态逐步改善，并提供前后对比图。

案例的重点不是单独讲结果，而是让客户看见萧岚苑具体如何参与解决。

### 4. 数据证明元素

作用：增强结论冲击力、可信度和紧迫感。

可以使用资料中已经确认真实有效的数据，包括但不限于：

- 20 余年国兰种植经验；
- 200 亩兰棚、2 千多个品种、年培育优质国兰超过 30 万株；
- 已服务的兰友规模和带领新手的真实数量；
- 经过验证的方法效果、病虫害风险、激素苗复花率、自然苗抗性等真实数据；
- 已确认的价格、服务内容、产品组成和使用周期；
- 真实案例中的时间、改善结果和成交结果。

数据不应孤立出现，通常和客户问题、案例或解决方案组合使用。

### 5. 同行对比元素

作用：解释客户为什么不能只比较价格，以及为什么选择萧岚苑。

完整结构：

> 市场常见做法 + 可能带来的具体问题 + 萧岚苑的不同做法 + 对客户的实际好处

可对比的方向：

- 只卖产品，与卖完后继续指导；
- 加温、激素快速催苗，与仿野生露天种植的自然老种苗；
- 客户自己摸索，与系统资料加一对一实操指导；
- 中间零售周转，与兰园基地直接挑苗发货；
- 只讲品种外观，与同时考虑地区、环境、复花和长期养护。

同行对比的落点必须回到客户利益，例如更容易适应家庭环境、少走弯路、出现问题有人承接。

### 6. 品牌实力元素

作用：建立“为什么相信我们有能力解决”的基础。

标准组成：

> 从业时间 + 基地规模 + 品种或培育规模 + 坚持的种植方式 + 陪伴服务差异

品牌介绍应服务于当前销售目的，不一定每次完整介绍。新客户可以用完整版本，客户已有具体问题时只选最相关的部分。

### 7. 具体方案介绍元素

作用：让客户从“知道有问题”进入“知道该怎么解决”。

标准组成：

> 当前问题 + 解决步骤 + 对应服务或产品 + 客户能得到的结果

陪伴养兰服务的方案可以拆成：

1. 用资料和视频建立基础；
2. 根据客户图片和环境进行一对一判断；
3. 在实际浇水、换盆、施肥、用药或促花时继续跟进；
4. 通过持续学习和反馈，让客户逐步具备独立养好的能力。

### 8. 痛点放大元素

作用：让客户意识到不解决问题的损失，形成行动动力。

标准组成：

> 当前小问题 + 继续发展的风险 + 可能造成的损失 + 现在处理的必要性

可使用的痛点方向：

- 焦尖、黄叶可能继续发展为根系或病害问题；
- 黑斑、腐苗、病虫害可能扩散；
- 品种和地区不适配会导致长期不开花或反复养不好；
- 没有系统方法会在浇水、植料、施肥和病虫害环节不断重复试错；
- 只比较低价可能买到不适配、退草或复花困难的苗；
- 错过真实的换盆、杀虫、促花或品种花期窗口，会增加后续处理成本。

### 9. 筑梦元素

作用：把产品功能转化成客户想要的生活结果和身份体验。

标准组成：

> 具体时间或场景 + 兰花呈现的状态 + 客户获得的感受 / 他人反馈 + 身份或文化价值

例如：春节满屋幽香、书房摆一盆文人兰、朋友来访时欣赏开花成果、从新手变成能把兰花养开花的人、收藏传统老种并长期传承。

筑梦应尽量具体，有画面，而不是只说“这款很好看”。

### 10. 下危机元素

作用：制造合理紧迫感，让客户从“以后再说”转为“现在处理”。

标准组成：

> 当前时间窗口 / 风险信号 + 真实数据或后果 + 延迟处理的损失 + 立即行动方案

常见方向：

- 当前是病虫害预防或处理的关键时期；
- 虫卵孵化、病害扩散后处理成本更高；
- 春秋季是生长、翻盆、分株或养护调整的重要时间；
- 带花、自然苗、特定品种或当前真实活动存在时间窗口；
- 客户现有做法继续下去可能造成烂根、腐苗或不开花。

### 11. 风险逆转元素

作用：降低客户担心养不好、买错和没人管的心理门槛。

可用方向：

- 仿野生自然苗本身更皮实；
- 根据客户地区和环境先做适配选择；
- 有资料、视频和师傅一对一指导；
- 遇到问题可以继续拍图反馈；
- 使用真实有效的补发、寄养、赠送或服务政策；
- 先从好养、性价比合适的品种开始尝试。

### 12. 行动指令元素

作用：让客户清楚下一步做什么，不让对话停在介绍上。

行动可以是：

- 回答一个问题；
- 发一张或几张照片；
- 在两个方向中选择；
- 查看资料、案例或商品；
- 确认品种、规格和数量；
- 点击商品卡片完成下单；
- 同意后续回访或让销售帮忙申请福利。

## 五、常用话术组合公式

### 组合一：案例说明 + 数据证明

适用：客户不相信方法有效，或者觉得自己的问题无法解决。

结构：

> 相似客户案例 + 具体解决过程 + 真实变化 + 规模 / 比例 / 时间数据 + 当前客户可复制的第一步

推进目标：让客户从怀疑转为愿意尝试陪伴养兰服务。

### 组合二：同行对比 + 具体方案介绍

适用：客户认为不同商家都一样，或者只比较价格。

结构：

> 同行常见做法 + 客户可能承担的后果 + 萧岚苑不同做法 + 陪伴服务的具体交付 + 对客户的直接好处

推进目标：建立萧岚苑的差异化价值。

### 组合三：专业判断 + 痛点放大 + 服务方案

适用：客户出现焦尖、黄叶、烂根、不开花等问题。

结构：

> 简洁判断可能原因 + 指出继续发展的风险 + 说明单次建议的局限 + 引出系统资料和持续指导

推进目标：从单点咨询自然转入陪伴养兰服务。

注意：判断到能够建立专业价值并引出服务即可，不为追求诊断完整而连续问很多细节。

### 组合四：客户经历 + 原因重构 + 风险逆转

适用：以前养死过、不会养、没有信心的客户。

结构：

> 接住失败经历 + 告诉客户不一定是他不会养 + 指出选苗和无人指导的影响 + 自然苗优势 + 陪伴服务兜底

推进目标：恢复客户尝试养兰的信心。

### 组合五：地区 / 环境 + 品种匹配 + 服务保障

适用：客户想买兰花或询问什么品种适合自己。

结构：

> 地区或摆放环境 + 品种习性判断 + 推荐品种优势 + 需要注意的地方 + 陪伴指导

推进目标：在推荐兰花的同时继续强化陪伴服务价值。

### 组合六：品种故事 + 文化价值 + 筑梦

适用：客户关注花香、品相、传统名品、收藏或精神体验。

结构：

> 品种历史 / 文化背景 + 花型花香特点 + 家庭或书房场景 + 客户拥有后的体验

推进目标：把商品从普通植物塑造成文化爱好和身份表达。

### 组合七：真实危机 + 数据冲击 + 立即方案

适用：病虫害、腐苗、季节窗口、真实稀缺或活动时点。

结构：

> 当前风险 + 真实数字或后果 + 延误损失 + 现在最合适的处理 / 购买动作

推进目标：缩短客户决策时间。

### 组合八：价值总和 + 二选一 + 低门槛行动

适用：客户认可价值但仍在选择。

结构：

> 重申与客户最相关的价值 + 给出两个清楚方向 + 明确更推荐哪一个 + 让客户完成一个简单选择

推进目标：降低选择成本，进入商品或服务卡片。

### 组合九：价格顾虑 + 价值拆解 + 成本对比

适用：客户说贵、买不起或想去比较。

结构：

> 接住价格顾虑 + 拆解买到的产品与服务 + 对比低价试错成本 + 提供性价比替代或申请福利

推进目标：把比较标准从单价转换为苗质、适配和持续服务总价值。

### 组合十：软拒绝 + 价值延续 + 后续钩子

适用：客户说谢谢、已经有了、暂时不需要、以后再说。

结构：

> 自然收住当前强推进 + 提供一个与客户有关的新价值 + 留下资料、季节提醒、品种故事或后续回访钩子

推进目标：不在同一轮强压，同时保留后续成交机会。

## 六、各销售环节的经验拆解

## 1. 破冰

审核结论：破冰按照现有模式，不做更改。本轮不引入品牌型、资料型、问题型或已购型破冰分流；继续使用现有的自我介绍、品牌图片，以及自然询问当前盆数和主要品种的开场结构。客户主动提出明确问题或购买需求时，仍按当前语义优先承接。
## 2. 挖需求

### 基本结构

> 告诉客户回答后能得到什么 + 只问一个关键问题 + 根据回答立即给一个判断或进入下一步

### 可选择的需求维度

- 地区与气候：用于品种和养护环境适配；
- 摆放空间：用于判断光照、通风、湿度和株型；
- 养兰资历：用于判断知识深度和服务需求；
- 现有问题：用于进入痛点和解决方案；
- 精神需求：以兰养心、享受花香、文化体验；
- 收藏与传承：传统铭品、瓣型、叶艺、稀有种源；
- 场景需求：春节、送礼、开业、书房、办公室；
- 预算与价格段：用于收敛兰花选择。

### 控制深度

- 不需要一次问完地区、经验、浇水、植料、光照、通风和预算；
- 有盆数和明确痛点后，通常先做简洁判断，再问“过去有没有人持续指导”即可向服务推进；
- 客户一旦认可自己缺少方法或指导，应及时开始塑造陪伴养兰服务；
- 只有某个信息会明显改变推荐时，才继续追问。

## 3. 找痛点

找痛点不是恐吓客户，而是把表面现象和实际损失连接起来。

### 基础痛点公式

> 客户症状 + 可能原因 + 继续发展的后果 + 过去处理方式的缺口 + 萧岚苑能怎样承接

### 新手痛点

> 怕养死 + 不知道从哪里学 + 网上信息杂 + 遇到变化不会判断 + 需要系统方法和有人指导

### 反复养不好

> 失败经历 + 不是单纯归因于客户能力 + 可能存在品种 / 苗情 / 方法 / 无指导问题 + 再买一盆仍可能重复 + 陪伴服务减少试错

### 有一定经验但管理不系统

> 盆数增加 + 病虫害和环境问题更复杂 + 单点处理容易反复 + 需要系统预防和管理 + 用陪伴服务建立完整体系

### 收藏与高阶客户

> 真假辨别 + 种源 + 品种档案 + 瓣型叶艺 + 价值判断 + 老师傅和兰园资源的专业支持

## 4. 推品

### 主推陪伴养兰服务

标准组成：

> 共鸣 + 相似案例 + 客户目前缺失的环节 + 四类服务内容 + 持续指导结果愿景 + 试成交

推荐时要说清楚：客户现在遇到的问题，正好对应服务中的哪一部分。

### 客户强烈需要兰花时

标准组成：

> 地区 / 环境 / 偏好 + 品类优势 + 具体品种 + 自然苗和兰园优势 + 同地区案例 + 陪伴服务保障 + 购买下一步

### 客户强烈需要养护产品时

标准组成：

> 症状方向 + 简洁原因判断 + 对应产品机制 + 具体使用方案 + 案例或数据 + 使用后的回访

即使推荐养护产品，也可以继续说明单一产品只处理一个环节，系统养护仍需要陪伴服务。

## 5. 塑品

塑品的本质是回答客户心里的五个问题：

1. 为什么这个方案适合我？
2. 为什么我现在需要解决？
3. 为什么要相信你们？
4. 为什么不选更便宜或其他商家？
5. 选择以后我能得到什么结果？

### 陪伴服务塑品公式

> 客户真实问题 + 单次建议的局限 + 资料解决基础 + 视频建立体系 + 师傅解决个体问题 + 案例 / 数据证明 + 养好后的愿景

### 兰花塑品公式

> 品类优势 + 地区适配 + 仿野生自然苗 + 同行苗质对比 + 基地与种源证明 + 同地区复花案例 + 后续服务保障

### 养护产品塑品公式

> 当前问题 + 产品成分 / 机制 + 使用方便性 + 与其他环节的组合效果 + 用前用后案例 + 使用方法

## 6. 试成交

试成交不是等待客户自己提出购买，而是用低门槛问题测试意愿。

### 常用结构

- 明确推荐 + 适配理由 + 是否帮客户安排；
- A / B 两个方向 + 主要差别 + 更建议的一款；
- 筑梦画面 + 服务保障 + 从一盆开始；
- 当前危机 / 时机 + 真实损失 + 立即解决方案；
- 风险逆转 + 简单行动，例如发卡片、挑苗、确认规格。

## 7. 逼单

逼单的重点是找出并解决最后一个卡点，不是重复介绍所有价值。

### 首次试探

> 明确这款适合客户 + 一句理由 + 询问是否挑选 / 预留 / 发购买入口

### 二次推进

> 针对客户最后顾虑 + 补充真实稀缺、寄养、服务或风险逆转 + 给出具体行动

### 最终促成

> 确认客户选择 + 强化购买后的承接 + 明确完成下单后的下一步

### 常见卡点的元素选择

| 卡点 | 优先使用的话术元素 |
| --- | --- |
| 太贵 | 关系承接 + 价值拆解 + 试错成本对比 + 性价比替代 / 申请福利 |
| 怕养死 | 原因重构 + 自然苗优势 + 陪伴服务 + 风险逆转 |
| 选择困难 | 回顾核心需求 + 明确主张 + 二选一 + 低门槛行动 |
| 不信任 | 品牌实力 + 相似案例 + 数据证明 + 具体服务过程 |
| 再考虑 | 轻量识别最后顾虑 + 只处理这一点 + 明确下一步 |
| 去别家看看 | 同行对比维度 + 客观比较标准 + 萧岚苑差异 + 保留触点 |
| 暂时不需要 | 自然收住 + 价值延续 + 季节 / 资料 / 品种钩子 |

## 七、典型来源场景的转化结构

### 1. 从来没养过或以前养死了

> 承接没有信心 + 用丰富好看的传统国兰建立兴趣 + 20 年经验背书 + 说明自然苗优势 + 陪伴养兰降低学习门槛 + 从好养品种开始试成交

### 2. 刚养三个月、暂时没有明显问题

> 邀请发图片 + 从品种、摆放、盆器、植料中快速找到一个可提升点 + 给一个专业判断 + 引出科学养护体系 + 推陪伴服务

### 3. 养了一年以上、反复出问题

> 复盘失败问题 + 从品种、种源、植料、病害和日常管理中提炼主要矛盾 + 用案例说明解决过程 + 强调系统管理 + 推陪伴服务

### 4. 朋友送的兰花

> 尊重礼物的情感价值 + 先帮助养好而不急于推销 + 请求整体和局部图片 + 给一个有用判断 + 分享相似案例 + 推陪伴服务 + 再种草更适合客户环境的兰花

### 5. 山上挖的兰花

> 法律风险和驯化成本 + 野生草不开花或价值不确定的风险 + 对比经典名品当前可得性 + 仿野生基地自然苗优势 + 推稳定复花品种和陪伴服务

### 6. 网上买的兰花

> 承接当前问题 + 说明网上常见不对版、激素苗或无人售后的风险 + 用客户苗情建立判断 + 对比萧岚苑种源和服务 + 具体品种塑品 + 推陪伴服务或自然苗

### 7. 花鸟市场买的兰花

> 说明基地熟悉批发流通链路 + 市场品种和苗质参差的辨别难度 + 对比基地直接挑苗 + 保真保质和持续指导 + 推荐经典好养品种

## 八、群发和日常互动经验

群发不是单向发广告，而是用内容触发客户回复，再根据回复进入对应销售结构。

### 客户说“谢谢分享”

> 接住认可 + 当前花期 / 季节机会 + 提供适合家庭养的品种或养护方向 + 开放式小问题

### 客户说“已经有了”

> 认可其经验 + 问最近养的品种 + 发图交流 + 从图片切服务或从品种切复购

### 客户说“太贵了 / 买不起”

> 接住价格 + 强调养兰的长期价值 + 举性价比品种 + 与客户看中的品相对比 + 给更适合的替代

### 客户说“不错但暂时不需要”

> 认可眼光 + 不在本轮硬压 + 植入当前季节的病虫害、换盆或养护提醒 + 留下下次交流理由

### 留客三种钩子

1. 价值延续：资料、小兰书、朋友圈、会员试看内容；
2. 场景痛点：雨天养护、换盆黄金期、季节性预防、节气表；
3. 反向互动：品种二选一、趣味猜题、发图交流，不用“要不要买”这种封闭问句。

### 内容节奏

- 每天可分享一个品种，用故事、文化、花型花香和场景建立兴趣；
- 间隔 3—5 天发送养护知识、案例或试看内容；
- 对沉默用户使用趣味问题、季节提醒和个性化知识重新激活；
- 每次触达都要有新的销售目的，不重复催问“考虑得怎么样”。

## 九、Agent 每轮生成回复的决策步骤

### 第一步：识别客户当前信号

客户当前是在：

- 说养护问题；
- 表达不会养或怕养死；
- 索要资料；
- 问品种；
- 问价格、规格、库存或链接；
- 表达价格、信任、效果或时机顾虑；
- 礼貌结束、软拒绝或沉默；
- 已购后需要服务。

### 第二步：确定这一轮唯一主要目的

从以下目的中选择一个：

- 让客户开口；
- 建立一个专业判断；
- 让客户承认痛点；
- 让客户看到陪伴服务缺口；
- 塑造服务或产品价值；
- 测试购买意愿；
- 解决最后顾虑；
- 完成下单；
- 为下一次跟进留下触点。

### 第三步：选择两到四个话术元素

例如：

- 黄叶咨询：关系承接 + 专业判断 + 痛点放大 + 服务方案；
- 客户怕养死：原因重构 + 案例说明 + 风险逆转 + 试成交；
- 客户说贵：价格承接 + 价值拆解 + 同行对比 + 低门槛方案；
- 客户问具体品种：地区适配 + 品种优势 + 服务保障 + 行动指令；
- 客户没回复：新价值 + 个性化钩子 + 容易回答的问题。

### 第四步：组织成自然微信表达

- 先回应客户，再给判断；
- 用客户听得懂的语言；
- 不把所有证据和服务权益一次堆完；
- 追问尽量浅，获得足够信号后就推进；
- 结尾有清楚行动，但不要求每轮都强行提问。

### 第五步：根据客户反应切换

- 客户认可痛点：转服务塑品；
- 客户问服务内容：具体介绍方案和权益；
- 客户问价格或链接：转真实商品查询与成交；
- 客户仍犹豫：识别并处理最后一个卡点；
- 客户拒绝：收住本轮，保留下次价值触点；
- 客户已购买：转入养护交付和长期复购关系。

## 十、需要沉淀的客户信息

Agent 每轮不需要主动问完，但应把对话中自然出现的信息逐步记录下来：

| 信息维度 | 作用 |
| --- | --- |
| 当前盆数、主要品种、养兰时间 | 判断客户层级和服务需求 |
| 地区、摆放环境、光照、通风、湿度 | 判断品种和养护适配 |
| 黄叶、焦尖、烂根、不开花等问题 | 找痛点和服务切入口 |
| 失败经历、是否长期自己摸索 | 判断客户信心和指导缺口 |
| 好养、花香、花色、叶姿、收藏偏好 | 兰花推荐和后续复购 |
| 预算、价格反应、选择困难 | 判断成交卡点 |
| 已发资料、案例、商品和客户反馈 | 避免重复并设计下一次推进 |
| 订单和已购商品 | 做好服务交付与复购承接 |

## 十一、数据与策略的使用说明

1. 原始实操资料中的企业数据、案例数据、效果数据、风险数据、产品数据和价格数据均按真实有效的业务经验保留，不因表达有销售冲击力而删除。
2. “筑梦、下危机、同行对比、数字冲击、风险逆转、逼单”等属于允许使用的销售策略，应教会 Agent 根据场景组合使用。
3. 数据的主要价值是证明、对比、制造紧迫感和降低决策风险；Agent 应将数据与具体客户问题组合，不机械堆砌。
4. 当前价格、库存、订单、物流、活动和实际执行结果仍按照系统现有方式查询和调用，避免把历史案例中的动态信息当成当前执行结果。
5. 本稿不新增硬边界；继续沿用项目已经确认的硬边界和人工接管规则即可。

## 十二、后续正式经验包建议格式

每条正式经验建议整理为：

- 经验名称；
- 解决什么销售判断；
- 适用客户信号；
- 如何理解；
- 可选择的话术元素；
- 推荐组合公式；
- 推进目标；
- 何时切换下一步；
- 参考案例；
- 常见失败方式。

每个优秀完整案例建议整理为：

- 客户背景；
- 之前发生了什么；
- 客户原话；
- 销售回复；
- 该回复使用了哪些元素；
- 为什么选择这些元素；
- 客户后续反应；
- 最终结果；
- 可以迁移的经验；
- 不能机械照搬的具体内容。

这样 Agent 学到的是销售人员在不同局面下的组合与判断能力，而不是只会匹配关键词和复制固定句子。
