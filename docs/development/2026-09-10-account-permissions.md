# 账号管理与员工权限

## 任务目标
- 将共享密码门禁升级为数据库账号密码登录，不提供注册。
- 保留管理员、测试身份，新增员工；管理员分配页面观看权限与员工可操作的微信。
- 仅管理员可见、可调用账号管理和权限分配功能。

## 实施计划
1. 增加账号、会话与登录限流存储，密码哈希保存；首次启动将现有管理员密码初始化为 admin 账号。
2. 增加创建账号、编辑权限、启停与重置密码接口；权限变更立即生效，重置和停用撤销会话。
3. 后端按页面授权，员工会话列表、详情、消息、客户资料与事件流限制到已分配微信；其他页面仅观看。
4. 前端增加账号登录、账号权限管理、菜单和路由过滤，展示真实操作人。
5. 针对登录、撤销、页面拒绝与跨微信越权进行最小必要验证，检查前端类型和构建，审阅差异后提交推送。

## 完成结果
- 新增数据库账号、随机登录会话、scrypt 密码哈希及登录失败限流；旧门禁 Cookie 停止使用。
- 新增仅管理员可见的“账号与权限”页面，支持创建、生成密码、重置、启停、页面观看权限与固定客服微信分配。
- 员工会话列表、详情、消息操作、客户资料、活动发送、实时事件均执行后端权限校验；操作人使用登录账号。
- 菜单与路由按页面授权过滤，其他资产与配置页面按观看权限开放；取消 Nginx 自动注入服务 API 密钥。
- 管理员初始化沿用现有配置密码，启动自动建表，账号数据库纳入现有备份，部署文档已说明迁移行为。
- 已补齐跨微信共用客户资料的保护：不能拆分的历史聚合资料仅向覆盖其全部微信的员工开放。
