# 视频点击触达统计

## 任务目标

- 先建立一条与正式触达隔离的视频卡片测试链路，用于验证用户点击触达统计。
- 用户在微信中点击视频卡片后直接进入视频，不出现登录、表单或 Agent 跟进。
- 统计可归因到客户、素材、触达任务和出站消息，并尽量排除微信预览请求。
- 保持“服务中定时触达”和其他原生视频发送链路不变；真实微信测试后再决定是否替换。

## 实施计划

1. 增加视频触达链接和点击事件数据表，使用随机不透明令牌实现客户归因和幂等复用。
2. 增加公开的轻量跳转页和播放跳转接口；首页请求不计数，只有可见页面执行播放跳转时记录触达。
3. 增加独立的后台测试发送接口，从已发布视频素材创建带封面的追踪卡片，复用现有易云 `sendUrl` 出站队列。
4. 增加独立测试查询接口，返回测试卡片的投递状态、是否已点击、首次/最近点击时间和总点击次数。
5. 配置 Nginx 将 `/v/` 公开路径代理到 API，不与后台 SPA 路由冲突。
6. 使用最小范围测试验证链接复用、预览不计数、点击去重/累计、跳转、测试卡片投递和统计口径，并验证正式定时触达代码未改变。
7. 根据真实微信测试反馈，将“落地页跳转 MP4”调整为同页 HTML5 视频播放器，同时尝试标准自动播放和微信 `WeixinJSBridgeReady` 播放，保留手动播放兜底。

## 完成结果

- 新增独立的视频触达测试发送与查询接口，测试消息使用现有易云链接卡片队列。
- 新增 `/v/{token}` 可见页面跳转和 `/v/{token}/play` 视频流代理，视频请求支持 Range 透传。
- 新增测试链接与打开事件持久化；同一次打开所产生的多个 Range 请求按播放会话去重，重新点击可累加。
- Nginx 新增 `/v/` 公开流式代理；测试公开域名可独立配置，生产默认使用 `https://sales-agent.hzwohu.com`。
- 未修改“服务中定时触达”服务及原生视频出站逻辑。
