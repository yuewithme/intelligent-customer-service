# 后台账号增删与账密设置

## 任务目标
- 管理员在后台新增、删除账号，并可直接编辑登录账号、设置密码，保存到后端数据库。
- 初始管理员登录账号设为 wohukeji，密码按用户本次指定值设置；密码不写入源码、开发日志或 Git。

## 实施计划
1. 扩展账号编辑接口及界面，支持用户名和手动密码设置，密码留空则保留原密码。
2. 增加删除账号接口及界面，撤销被删除账号会话，保留当前管理员自我保护。
3. 初始管理员用户名可配置且默认 wohukeji；已验证现有管理员可登录，发布后通过账号管理 API 修改当前初始管理员账密，不在服务器编辑源码。
4. 针对账密修改、删除与权限保护验证，检查前端类型与构建，提交推送并验证线上指定账号登录。

## 完成结果
- 后台编辑账号可修改用户名、姓名、权限和密码；密码留空保留原值，手动设置允许至少 6 位。
- 后台可删除其他账号，数据库同步删除并撤销会话；不能删除当前登录管理员，历史业务记录保留。
- 登录名或密码变化后旧会话撤销，当前管理员修改自己的账密后返回登录页。
- 初始管理员用户名默认为 wohukeji，可通过 ADMIN_GATE_USERNAME 配置；指定密码通过正式账号管理 API 写入数据库，不写入 Git。

## 验证情况
- 25 项账号权限及相关接入验证通过，包含修改账密、保留原密码、重名回滚、删除会话撤销、管理员保护和初始化用户名。
- 前端类型检查与生产构建通过。
- 待提交发布后，执行当前管理员账密同步和线上登录核验。
