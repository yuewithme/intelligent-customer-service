# 工作台流程编辑与节点比例

## 任务目标

- SOP 画布支持节点拖动、新增、删除、编辑及连线调整，保存后后端按同一份配置执行。
- 所有节点统一缩小顶部类型文字与留白，放大业务标题，协调卡片高度、边距与连线。

## 实施计划

1. 建立带版本校验的持久化流程定义，校验入口、节点、连线和定时动作，接入对话路由及调度/发送前校验。
2. 工作台新增编辑与保存操作、节点增删、连线编辑、拖动定位；修改内容和执行配置一起保存。
3. 统一节点视觉比例，在独立本地环境验证编辑、持久化和运行时变化，完成差异审查后按默认流程提交推送。

## 完成结果

- 三个 SOP 共用可编辑流程定义，支持拖动、增删节点、编辑入口标签条件、对话执行目标、转人工/意向条件、触达时间与素材类型，以及连线增删和目标调整；点击“保存并生效”后持久化。
- 对话运行时读取同一份定义，限制可到达节点并保存推进位置；定时调度及发送前检查读取节点配置，删除节点或修改执行规则后拦截旧任务。仅调整布局不会重置客户推进位置。
- 首单新好友接待按修改后的入口条件与对话目标执行；原有三个总开关继续独立控制，种草保持关闭。
- 所有画布节点统一为 208×80，缩小顶部类型文字和边距，放大业务标题；定时节点直接展示实际调度配置，编辑时间时同步默认时间标题和连线标签。
- 同步更新带“每天”前缀的种草时间说明；编辑后经验包简介不再显示旧版固定时段或分支数量。

## 验证情况

- 已核查：当前流程图由后端固定构造，节点列表与触达时段分别写在代码中；本任务需要将编辑后的定义接入真实执行，不能仅保存坐标。
- 后端相关检查通过，覆盖 API 持久化与版本冲突、无效图校验、入口变化、实际调度变化、节点删除后停止执行、自定义对话节点、连线推进、新好友入口和消息发送控制。
- 前端类型检查与生产构建通过；独立本地数据库的浏览器操作验证了节点新增、执行目标编辑、连线新增、拖动坐标保存、节点及其连线删除和刷新持久化，未修改线上流程或发送客户消息。
- 已查看节点截图并核对卡片尺寸、标题比例及窄屏编辑面板；发布前完成差异与敏感信息检查，按项目默认流程提交至 GitLab main。
