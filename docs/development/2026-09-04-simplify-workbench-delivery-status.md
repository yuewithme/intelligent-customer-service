# 简化工作台消息发送状态

## 任务目标

- 去除客服会话消息中面向运维的多组发送状态、错误详情、尝试次数和易云消息 ID。
- 日常客服界面只保留消息内容；仅在需要人工处理时显示一个统一的异常提示和重发入口。

## 实施计划

1. 隐藏排队、发送中、已受理、已确认等过程和成功状态。
2. 仅将明确失败的发送状态统一显示为“发送失败”。
3. 移除会话卡片中的技术错误文案、尝试次数和易云 ID，将“立即补发”简化为“重新发送”。
4. 执行前端类型检查并审查最终差异。

## 完成结果

- 工作台会话不再显示排队中、发送中、已受理、待人工核验、发送结果未知、已确认和已取消等状态。
- 会话气泡不再显示发送错误原文、发送尝试次数和易云消息 ID。
- 仅 `failed` 和 `waiting_material` 两类明确失败显示统一的“发送失败”与“重新发送”。
- 取消了未确认消息在会话区的手工补发入口，避免客服误操作导致重复发送。

## 验证情况

- `pnpm ts:check` 通过。
- `pnpm build:prod` 通过。
- 已检查目标组件最终差异，未改动后端投递状态和会话消息数据。
