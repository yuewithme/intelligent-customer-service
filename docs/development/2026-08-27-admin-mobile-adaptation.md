# 管理后台手机端适配

## 任务目标

- 仅在手机端启用新的响应式布局，保持电脑端现有导航、三栏工作台和业务交互不变。
- 为手机端提供可见的后台导航入口，并保证会话选择、消息查看、人工回复和客户资料查看能够顺利完成。
- 改善回复工具栏、媒体消息和常用管理页面在窄屏下的可用性，避免整页横向溢出。

## 实施计划

1. 在全局后台布局中增加手机端顶部栏和抽屉导航，收纳微信账号切换、完整菜单和退出操作。
2. 将手机端工作台改为“会话 / 聊天回复 / 客户资料”单视图切换，选择会话后自动进入聊天回复。
3. 调整聊天消息、回复输入区、客户侧栏和通用内容容器的窄屏尺寸与安全区域。
4. 为包含筛选栏、卡片网格和宽表格的后台页面补充最小必要的手机端样式。
5. 执行 TypeScript 检查和生产构建，审查最终差异后提交并推送。

## 完成结果

- 后台在 820px 及以下启用抽屉导航，手机端可切换微信账号、访问完整菜单并退出登录。
- 工作台在手机端改为“会话 / 聊天回复 / 客户资料”单视图切换；选择会话或通过带会话参数的链接进入时会自动打开聊天回复。
- 聊天视图复用现有监督面板的回复组件，保留接管、文字、图片和表情回复能力，并为消息媒体、长文本和选择工具栏补充窄屏尺寸。
- 通用内容容器、弹窗、确认框、登录页以及产品、养护手册、销售活动、转人工设置、销售案例库和能力工作台均补充了手机端布局约束。
- 所有响应式规则均限定在手机端断点内，桌面端现有布局和业务逻辑未调整。

## 验证情况

- `pnpm ts:check` 通过。
- `pnpm build:prod` 通过，Vite 成功构建全部后台资源。
- 本地开发服务器首页请求返回 200，构建产物中已确认生成移动端回复视图样式。
- `git diff --check` 通过；本地未启动后端服务，因此未执行需要真实会话数据的端到端回复操作。
