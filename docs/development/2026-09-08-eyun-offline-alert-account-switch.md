# 易云换号后的离线告警优化

## 任务目标
- 修正管理后台切换 WID / WCID 后旧监控状态可能干扰告警的问题。
- 将易云 `offlineReason` 返回的嵌套 JSON / XML 错误整理成可读的飞书告警，并提供明确处理建议。

## 实施计划
1. 为手动账号配置变更加版本标识，并在保存新账号时重置登录监控状态。
2. 登录监控在外部查询返回和发送告警前核对配置版本，丢弃换号前发起的旧查询结果。
3. 从易云掉线原因中的 JSON、XML CDATA 和错误字段提取核心文本，限制兜底文本长度。
4. 增加针对换号竞态与真实告警样例的定向测试，检查差异后提交、推送并验证生产发布。

## 完成结果
- 手动保存不同 WID / WCID 时会推进配置版本并清空旧监控状态；换号前发起的在线列表、掉线原因和待发送状态更新均会被丢弃。
- 飞书告警会从易云嵌套 JSON / XML 的错误字段提取核心原因，最长保留 240 字，避免整段技术报文刷屏。
- 对“请重新登录”类原因增加可执行建议：在 Eyun 控制台重新登录，继续使用告警中的 WCID，成功后的 WID 由登录监控自动同步。

## 验证情况
- 已核对易云官方文档：`offlineReason` 的 `reason=null` 表示在线，返回明确原因时应处理原因后重新登录；掉线重登应继续使用原 `wcId`。
- 用户提供的原始原因可解析为“登录出现错误，请你重新登录。”，属于易云登录态错误，不是飞书发送错误。
- 定向后端测试 14 项通过，覆盖原有离线确认、恢复通知、失败重试、回调去重、在线判定，以及新增的原因解析、账号换号状态重置和旧查询告警拦截。
