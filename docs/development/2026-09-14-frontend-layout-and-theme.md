# 前端排版与配色优化

## 任务目标

使用用户指定的 design-taste-frontend skill 审查现有运营后台，改善长时间使用时的布局舒适度、文字层级和配色一致性，保留现有导航、业务流程与品牌标识。

## 现状审查

- 技术体系为 Vue 3、Element Plus、UnoCSS；沿用现有组件，不迁移框架或新增设计库。
- 品牌为小兰 Agent，绿色为既有品牌色；当前深绿侧栏、业务绿与组件默认蓝混用。
- 全局未统一字号、行高、控件和色彩变量，公共页面间距及标题不一致。
- 工作台固定三栏最小宽度超过常见笔记本可用宽度；中等宽度时右栏换行但父容器限制高度，内容会被裁切。
- 能力工作台固定列宽挤压画布；窄屏查看模式隐藏详情，影响查看。
- skill 主要适用于营销与展示页面。后台采用其审查、保留结构、排版、间距、对比度方法；营销 Hero、装饰图片和高强度动画规则不适用。

## 实施计划

1. 建立品牌绿、统一中性色、14px 正文及合理行高、8px 控件与12px面板圆角；设计参数为 DESIGN_VARIANCE=3、MOTION_INTENSITY=2、VISUAL_DENSITY=5。
2. 优化侧栏、顶栏与公共页面容器，统一标题、说明、表格、筛选区和弹窗视觉。
3. 调整工作台三栏比例、列表筛选和消息气泡；中等屏幕保留可滚动的监督区，手机保持原有会话切换与回复流程。
4. 修正能力工作台列宽及详情区域响应式布局，处理受影响的管理页面。
5. 本地浏览器检查桌面、笔记本及手机布局和关键交互，运行前端类型检查、生产构建、diff检查；完成后按仓库约定提交并推送 main。

## 完成结果

- 统一品牌绿、中性色、正文行高、控件高度、标题与说明文字；保留红色错误、琥珀色警告等语义状态色。
- 侧栏由深色改为浅色，缩减占宽，沿用 Element Plus 图标；顶栏样式限定在实际文字元素，避免影响选择器内部布局。
- 公共页面采用统一间距，移除全屏白色外框；表格、设置面板、统计卡片和弹窗保留明确的白色内容区域。
- 工作台改为自适应三栏并占满可用高度，中等屏幕的监督区完整排列在下方；改进会话筛选布局、选中态、消息可读性和媒体边界。
- 能力工作台的画布局部滚动，窄屏详情展示在下方；手机统计卡片改为并排，保留更多业务内容可见空间。
- 补充焦点可见样式、刷新按钮和登录输入框的可访问名称，以及减少动态效果设置。
- 未新增依赖、测试框架，未修改后端接口、导航地址、业务权限或消息处理逻辑。

## 验证情况

- 前端 `pnpm ts:check` 与 `pnpm build:prod` 通过。
- 浏览器检查10个主要管理页面在1366、1024、390px下的布局；另对工作台、标签、养护、能力工作台补充320、768、1600px及修改后的手机布局检查。已检查组合均无整页横向溢出或页面脚本异常。
- 验证会话选择、手机客户资料切换、手机侧栏展开，以及能力节点选择后详情更新；截图检查了聊天媒体、统计卡片和设置面板。
- 登录页、在线体验页和账号创建弹窗在320、1366px下补充检查通过；弹窗内容区域独立滚动，限制桌面长表单高度。
- 新增主题的正文、次要文字、占位文字、主要按钮及状态按钮文本对比度均不低于4.5:1；主要按钮正常态5.64:1、悬停态6.94:1。
- 本地前端5184代理本任务后端8014；后端使用本地数据库副本并开启 evaluation mode，浏览器数据、检查脚本、截图和构建产物不进入Git。
- `git diff --check`、逐文件差异审查及暂存区凭证扫描通过；仅提交前端修改和本任务开发日志，发布遵循仓库的GitLab main流程。
