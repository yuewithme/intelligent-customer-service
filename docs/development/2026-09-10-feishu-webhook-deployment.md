# 通过 GitLab 部署更新飞书通知地址

## 任务目标
- 将飞书通知 webhook 更新为用户提供的新地址，通过现有 GitLab 自动部署生效，地址不写入 Git。

## 实施计划
1. 流水线接受可选的 FEISHU_HANDOFF_WEBHOOK_URL 部署变量，更新生产受控环境文件。
2. 更新时校验地址、保留环境文件权限及其他配置，随后按原流程部署。
3. 在验证阶段比较 API 容器实际配置与传入地址，日志只输出匹配结果。

## 完成结果
- 已增加可选部署变量注入与容器实际值校验，实际地址通过本次推送的 CI 变量传入，保存在生产环境文件中。
- 配置更新在部署锁内执行，原文件权限、属主及其他配置保留，不传变量的部署继续沿用服务器已保存的地址。

## 验证情况
- 当前通知代码读取 FEISHU_HANDOFF_WEBHOOK_URL；仅推送现有代码不能改变服务器环境文件。
- 本地已验证配置保留、重复配置去除、校验一致时通过及不一致时拒绝；Python、CI YAML 与部署/验证阶段 Shell 语法检查通过。
