# 微信端人工回复同步修复

## 任务目标

- 修复微信客户端发出的人工回复未稳定记录到后台会话的问题。
- 防止微信系统事件被当作客户的“[非文本消息]”并触发人工接管。

## 实施计划

1. 根据易云回调中的 `self`、`wcId`、`fromUser` 和 `toUser` 综合判定消息方向。
2. 仅对方向明确的微信端外发消息写入 `human / wechat_client`。
3. 过滤明确的微信系统 XML 事件，保留真实图片、视频、语音等非文本消息。
4. 执行最小范围的回调与消息同步验证，检查最终差异。

## 完成结果

- 易云私聊回调不再只依赖 `data.self`：当 `fromUser` 等于当前登录微信 `wcId`，且 `toUser` 是另一个联系人时，同样按微信客户端人工外发记录。
- 系统事件分类提前到外发同步之前，即使回调带有 `self=true`，明确的 `sysmsg` 也不会进入后台会话。
- 客户入站、已排队外发回执确认和真实非文本分类逻辑保持不变。

## 验证情况

- 微信客户端 `self=true`、`self` 缺失、`self=false` 但方向字段明确三种人工外发场景通过。
- 普通系统事件与 `self=true` 系统事件过滤场景通过。
- 已排队 AI 消息的外发回调去重与确认场景通过。
- 定向用例共 6 项通过；目标 Python 文件编译通过。
- 扩大到两个相关测试文件时为 30 项通过、1 项既有断言失败：后台主动发送路径当前返回 `accepted`，旧用例期待 `sent`。该路径不经过本次修改的微信客户端回调判向，本任务未改动其状态语义。
