# 模型配置页新增 WID / WCID

## 任务目标
- 在管理后台“模型配置”页可视化读取、编辑并保存易云 WID、WCID，使后端运行配置同步更新并在重启后保留。

## 实施计划
1. 增加专用账号配置表和受管理员权限保护的读取、保存接口，未保存时沿用环境配置。
2. 服务启动时加载保存值，保存成功后更新当前进程配置；登录监控刷新 WID 时同步持久化，忽略手动修改前发起的过期查询。
3. 替换模型配置占位页，增加字段说明、加载和保存反馈、必要输入校验。
4. 验证保存回显、重启恢复、权限、监控同步与前端构建，检查最终差异后按项目规则提交并推送 main。

## 完成结果
- “模型配置”页新增微信接入配置，可读取、编辑、保存 WID / WCID，支持重新加载、输入校验及失败反馈。
- 新增管理员专用配置接口与持久化表；保存成功立即更新后端 Settings，服务启动优先加载数据库保存值。
- 登录监控刷新同账号 WID 时同步保存；手动保存前发起的过期查询不会覆盖新配置。
- 开发与本地验证完成，待提交推送并确认发布结果。

## 验证情况
- 已确认生产为单 Uvicorn 进程，运行时共用缓存 Settings；配置使用生产持久化数据库保存。
- 已查阅易云官方 API 参考及登录文档：wId 是登录实例标识，wcId 是微信 ID；不新增外部 API 调用。
- 定向后端检查 12 项通过，覆盖环境值回显、保存归一化、运行时更新、重启恢复、非法输入、管理员权限、监控持久化与过期查询保护。
- 前端类型检查与生产构建通过。
- 浏览器在本地临时数据库完成填写、保存及刷新验收，页面和后端接口均回显保存值，截图确认布局正常；未修改线上账号值。
