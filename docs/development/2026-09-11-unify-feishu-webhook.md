# 所有飞书通知统一发送地址

## 任务目标
- 所有飞书通知使用已提供的新 webhook，删除旧的独立告警地址配置。

## 实施计划
1. 去除通用告警对 FEISHU_ALERT_WEBHOOK_URL 的优先读取，统一使用 FEISHU_HANDOFF_WEBHOOK_URL。
2. 部署更新脚本清除旧告警配置，验证环境文件及 API 容器均不再保留该配置。
3. 定向验证发送目标选择及配置迁移，再推送 GitLab 自动部署并检查验证结果。

## 完成结果
- 通用告警与转人工、微信离线通知统一使用 FEISHU_HANDOFF_WEBHOOK_URL，删除旧独立告警字段与示例配置。
- 部署迁移清除环境文件中的旧告警地址，部署验证同时检查新地址一致性和环境文件、API 容器中旧变量已移除。

## 验证情况
- 已确认此前更新脚本只更新转人工地址，通用告警仍优先读取独立告警地址。
- 20 项定向检查通过，覆盖通用发送地址、旧地址不得回退、离线监控、转人工和有赞通知路径；迁移检查确认旧配置及重复项移除，其他配置保留。
