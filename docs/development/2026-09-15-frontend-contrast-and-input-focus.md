# 前端深浅配色与输入框焦点调整

## 任务目标

增强界面深浅对比；文本框点击前后保持相同样式，不出现高亮、描边或阴影变化。

## 实施计划

1. 使用深绿侧栏、浅灰绿页面底色与白色内容区域，增强导航、表头和选中项的层次；手机顶栏与抽屉采用同一深色。
2. 根据用户补充要求，文本输入框、文本域和选择器点击前后保持相同边框与阴影，不添加高亮或外框；按钮和导航继续保留键盘焦点提示。
3. 在本地检查桌面、手机和表单焦点效果，运行前端构建及差异检查，通过后按仓库约定提交推送main。

## 完成结果

已采用深绿侧栏、浅灰绿页面背景和白色内容区域，强化正文、分隔线和表头的对比；手机顶栏与导航抽屉使用同一深色。

输入框、文本域与选择器的悬停及聚焦样式保持默认边框和阴影，移除文本输入元素的绿色焦点外框。按钮与导航仍保留键盘焦点提示。

## 验证情况

在 1366px 桌面与 390px 手机视口检查工作台、标签管理、转人工设置及登录页，并查看桌面工作台与手机导航截图。页面未出现横向溢出或脚本异常。

通过浏览器实际点击搜索框、登录输入框、文本域和选择器，确认元素成功获得焦点，且点击前后的边框、背景、阴影与外框计算样式完全一致。

`pnpm build:prod` 与 `git diff --check` 通过。本地预览页面已更新，并保持在已登录的工作台。本任务仅调整前端样式，不更改业务接口、数据与权限。
