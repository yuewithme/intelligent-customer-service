# 案例8：静中观明月

## 一、客户背景

| 项目 | 内容 |
|------|------|
| 客户昵称 | 静中观明月 |
| 地区 | 青海省西宁市 |
| 养兰经验 | 零基础新手 |
| 当前情况 | 尚未购买兰花 |
| 核心需求 | 选择适合当地的新手品种并学习养护 |

---

## 二、客户痛点

客户第一次接触兰花，不了解青海地区适合养什么品种，担心光照和气候影响养护，希望购买一株适合新手、价格适中的兰花，并获得专业指导。

---

## 三、聊天记录（整理版）

### 客户

老师您好，我还没养过兰花，刚看了直播。我在青海西宁，室内夏天光照一般，不知道能不能养好兰花？

### 商家

当然可以。兰花没有想象中那么难养，关键是两点：

- 选择适合当地的品种；
- 有专业老师指导养护。

### 客户

我不知道青海适合养什么品种。

### 商家

根据您当地气候，建兰最适合新手。建兰耐旱、耐寒、适应能力强，而且现在正值花期，一年可开花三次左右，非常适合作为第一株兰花。

### 商家

您喜欢花色艳丽还是素雅？预算大概多少？

### 客户

喜欢素雅一点，先买便宜些练练手。

### 商家

推荐您建兰《青山玉泉》。

特点：

- 素花名品
- 香味清雅
- 抗病性强
- 老种苗
- 带花苞发货
- 一年可开花三次左右

我们不仅提供单品养护资料，还会一对一指导，并开放会员视频课程。

### 客户

橱窗里能买吗？

### 商家

这是微信会员专属品种，我发您专属购买链接。

### 客户

链接显示是花盆？

### 商家

苗子已经种在花盆里发货，收到即可养护。

### 客户

好的，我就买这个，以后养好了再换盆。

### 商家

没问题，后续换盆时我也会指导您。

### 客户

已经下单了。

### 商家

感谢支持。我马上安排挑选壮苗、消杀发货，同时开通视频课程，并发送《青山玉泉》养护资料。以后您把养兰环境拍给我，我会长期指导，并根据当地环境持续推荐适合的品种。

### 客户

谢谢老师，服务真好，很贴心。

---

## 四、成交结果

- 成交产品：建兰《青山玉泉》
- 开通会员视频课程
- 提供单品养护资料
- 提供长期一对一养护指导
- 安排挑选壮苗后发货

---

## 五、成交亮点

1. 根据客户地区推荐最适合的新手品种，增强专业信任。
2. 根据预算、喜好精准推荐产品，降低购买门槛。
3. 强调"产品+课程+长期指导"的整体服务价值。
4. 成交后立即开通课程、发送资料并安排后续养护跟进，提升客户体验。
