# 案例3：C60617 李允会

## 一、客户背景

| 项目 | 内容 |
|------|------|
| 客户编号 | C60617 |
| 地区 | 河南郑州 |
| 养兰经验 | 有少量养兰经验 |
| 当前问题 | 兰花养不开花，希望有人指导 |
| 是否本店客户 | 否（误认为已购买本店产品） |

---

## 二、客户痛点

客户之前购买过兰花，但不是本店商品，缺乏专业指导，导致一直不会养、不开花，希望有人手把手教学，并购买适合当地的新手品种。

---

## 三、聊天记录（整理版）

### 客户

家里已经有几盆兰花了，没人教，养不开花，等学会了再买。

### 商家

很多兰友都遇到过类似问题，养兰不仅要会养，更要选对适合当地的品种。我们提供一对一指导，帮助兰友把兰花养好。

### 客户

我买你家的兰花，不是说有教程吗？

### 商家

请把订单截图发给我，我先确认购买记录，并根据购买品种发送对应资料。

### 商家

经核实，您购买的是其他店铺的兰花，不是我们店。不过没关系，我先发您养兰资料学习，后续也欢迎体验我们的苗子和指导服务。

### 客户

原来如此，那麻烦您推荐几种适合我的兰花，最好能视频教学。

### 商家

您在河南，比较适合建兰。建兰耐热耐旱，非常适合新手。请告诉我预算以及喜欢的花色和香味。

### 客户

喜欢花色艳丽、香味浓郁，不想买太贵。

### 商家

推荐两款：

- 建兰《天地之华》：2-3苗带花，32.8元。
- 建兰《市长红》：2-3苗带花，39.9元。

两盆一起优惠70元，并提供养护资料、视频课程和一对一指导。

### 客户

家里盆和植料不够。

### 商家

塑料盆可以继续使用，我再送您一些植料，并帮您挑选壮苗。

### 客户

好的，我下单。

### 商家

请通过专属链接下单，下单后我安排发货，并开通课程权限。

### 客户

已下单成功，不过周末要回老家，请晚一天发货。

### 商家

没问题，我按您的时间安排发货。收到后有任何问题都可以联系我，我会持续指导养护。

---

## 四、成交结果

- 成交产品：建兰《天地之华》+《市长红》
- 成交金额：70元
- 赠送：植料
- 开通视频课程
- 提供一对一养护指导
- 按客户要求延迟发货

---

## 五、成交亮点

1. 发现客户并非本店老客户，仍主动提供帮助，建立信任。
2. 根据地区、预算和喜好精准推荐品种。
3. 主动解决盆和植料问题，降低购买顾虑。
4. 提供课程、资料和长期指导，提升服务价值。
