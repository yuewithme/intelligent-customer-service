# 案例9：月中独酌

## 一、客户背景

| 项目 | 内容 |
|------|------|
| 客户编号 | C60622 |
| 客户昵称 | 月中独酌 |
| 地区 | 江西赣州 |
| 养兰经历 | 多次养兰失败 |
| 当前问题 | 烂根、枯叶、不开花 |
| 购买渠道 | 抖音商城 |

---

## 二、客户痛点

客户多次养兰均出现烂根、枯叶、不开花，错误使用草木灰和旧植料，不懂兰花养护，希望重新购买适合的新手品种，并学习正确的养护方法。

---

## 三、聊天记录（整理版）

### 客户

之前养了几次兰花，都烂根了，现在想重新买几盆试试。

### 商家

请具体说说之前遇到的问题。

### 客户

烂根、枯叶，也不开花，之前一直在抖音买，没有人指导。

### 商家

您的问题主要来自三个方面：

- 植料透气性不足；
- 浇水和湿度控制不当；
- 可能购买了科技苗。

另外，草木灰属于碱性，不适合兰花，兰花喜欢微酸环境。

### 客户

原来如此。我想买带花苞的兰花，最好便宜一点，香味浓一些。

### 商家

推荐建兰《东方红荷》。

特点：

- 带花苞发货
- 花香浓郁
- 一年可开花三次左右
- 新手容易养护
- 2-3苗售价26.8元

同时提供：

- 单品养护资料
- 视频课程
- 一对一指导

### 客户

植料和肥料怎么办？

### 商家

建议使用新的兰花专用植料，不要继续使用旧植料，以免残留病菌。

肥料赠送几包供您学习使用。

苗子26.8元，植料39.9元，一起优惠66元。

### 客户

可以，直接发货吧。

### 商家

请提供收货地址，我安排挑苗、消杀后发货，并发送养护资料、植料使用说明及视频课程。

---

## 四、成交结果

- 成交产品：建兰《东方红荷》
- 配套产品：兰花专用植料
- 成交金额：66元
- 赠送：肥料
- 提供视频课程
- 提供植料使用说明
- 长期一对一养护指导

---

## 五、成交亮点

1. 纠正客户错误养护观念（草木灰、旧植料）。
2. 从病害原因切入，建立专业信任。
3. 根据预算推荐高性价比带花苞品种。
4. 组合销售苗子+植料+课程+指导，提高客单价和客户满意度。
