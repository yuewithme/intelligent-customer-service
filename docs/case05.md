# 案例5：C60615 捕风汉子

## 一、客户背景

| 项目 | 内容 |
|------|------|
| 客户编号 | C60615 |
| 客户昵称 | 捕风汉子 |
| 地区 | 四川省泸州市 |
| 养殖品种 | 建兰、金边达摩 |
| 当前问题 | 担心兰花不开花，缺少系统养护知识 |
| 商家指导 | 无 |

---

## 二、客户痛点

客户刚接触养兰，通过直播学习零散知识，没有系统资料，也没有专业指导，最担心的是兰花后期不开花，希望获得完整的养护方法。

---

## 三、聊天记录（整理版）

### 客户

老师，资料在哪里领取？我养了几盆建兰和金边达摩，最担心的是以后不开花。

### 商家

请问您在哪里？这些兰花养了多久？目前有没有遇到什么问题？

### 客户

我在四川泸州，养了两个月左右，目前没什么问题，就是怕以后不开花。

### 商家

只要苗子健康、苗龄够、环境合适，正常养护都可以开花。请问这些兰花在哪里买的？有没有人指导您？

### 客户

都是抖音买的，没有师傅指导，平时都是看直播学习，也没有系统资料。

### 商家

直播内容未必适合每个地区和品种。我先发您养兰资料学习，不过真正养好兰花，更重要的是有人手把手指导和长期实践。

### 客户

好的，谢谢。

### 商家

除了资料，我们还有上百节视频课程，针对不开花、夏季养护等问题都有详细讲解，并提供一对一指导。

### 客户

我觉得养兰确实会上瘾，我愿意继续学习。

### 商家

如果您想系统学习，可以加入陪伴养兰会员。

会员包含：

- 一对一指导
- 百节视频课程
- 夏季养护课程
- 开花管理课程
- 60天养死包赔
- 赠送建兰《七仙女》

活动价39.9元，终身有效。

### 客户

40元加入还送兰花吗？

### 商家

是的，赠送的品种价值已经超过会员费用，我们主要希望更多兰友体验专业指导和长期服务。

### 客户

愿意加入。

### 商家

我发送会员专属链接，填写地址即可下单。

### 客户

已经下单。

### 商家

收到。我先为您开通视频课程，并发送《七仙女》养护资料，以及服盆、浇水、定根水、6月养护等课程。后续请把养兰环境拍给我，我会根据当地环境继续指导您养护。

### 客户

好的，白天拍给您。

---

## 四、成交结果

- 成交产品：陪伴养兰会员
- 成交金额：39.9元
- 赠送：建兰《七仙女》
- 开通视频课程
- 提供资料及长期一对一指导

---

## 五、成交亮点

1. 从客户担心不开花切入，分析影响开花的关键因素。
2. 对比直播知识和系统学习，突出专业指导价值。
3. 展示课程体系与长期陪伴服务，增强客户信任。
4. 成交后立即开通课程并安排后续环境指导，提高客户体验。
