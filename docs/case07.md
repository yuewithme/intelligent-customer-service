# 案例7：苹果

## 一、客户背景

| 项目 | 内容 |
|------|------|
| 客户昵称 | 苹果 |
| 养兰经验 | 约1年 |
| 兰花数量 | 9盆 |
| 当前问题 | 烂根、腐苗、叶片腐烂 |
| 当前情况 | 已有2盆出现严重病害 |

---

## 二、客户痛点

客户养兰一年左右，不懂夏季养护方法，已有两盆兰花出现烂根、腐苗，担心病害继续扩散，不知道如何处理，希望获得专业指导。

---

## 三、聊天记录（整理版）

### 客户

老师，我养的兰花从根部开始烂叶，请帮我看看。

### 商家

从照片来看，已经出现严重烂根和腐苗。

主要原因是植料透气性不足，加上夏季没有根据气温调整盆内湿度，导致根部长期闷湿，引起病菌感染。

### 商家

家里一共养了多少盆？都是这种情况吗？

### 客户

一共9盆，目前有2盆这样。

### 商家

养多久了？是不是不太懂夏季养护？

### 客户

去年开始养，是的，不太懂。

### 商家

没关系，我们长期指导兰友养兰，遇到很多和您一样的问题。

您现在最重要的是：

- 及时杀菌处理；
- 更换透气植料；
- 避免病菌继续传播。

### 商家

这些处理方法您知道吗？

### 客户

不知道。

另外端午节会员活动还有吗？如果可以，我想参加学习。

### 商家

活动已经结束，不过我可以帮您申请活动价格。

加入会员后，我们会：

- 一对一指导处理烂根、腐苗；
- 提供病害处理视频课程；
- 教您夏季养护、植料搭配和浇水方法；
- 长期跟踪指导，避免再次发生类似问题。

---

## 四、成交结果

- 客户表达参加会员学习意向
- 商家申请保留活动优惠
- 进入会员咨询阶段

---

## 五、成交亮点

1. 根据图片快速判断病害原因，建立专业信任。
2. 明确指出病害传播风险，提升客户重视程度。
3. 将客户关注点从"救这一盆"转变为"系统学习养兰"。
4. 利用优惠活动作为成交契机，引导客户进入会员体系。
