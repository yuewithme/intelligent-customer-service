# 十个销售案例统一整理与事实分析

## 1. 文档目的

本文对 `case01.md` 至 `case10.md` 进行统一结构化整理，作为后续能力建模、差距分析和评测题设计的事实底稿。

整理原则：

- 仅记录原案例明确提供的信息；
- 原文未说明的字段统一标记为“未提及”；
- 不把销售原话直接认定为专业标准答案；
- 不评价销售策略是否正确；
- 不补充外部兰花知识、商品政策或推测信息；
- “成交完成”与“表达购买意向”分开记录。

## 2. 统一字段定义

| 字段 | 口径 |
|---|---|
| 客户阶段 | 原文描述的新手、已有经验、长期养护或多次失败状态 |
| 主要诉求 | 客户在聊天中明确表达的核心需求 |
| 问题类型 | 病害、养护、复花、选品、价格、物流、售后等事实标签 |
| 销售目标 | 该案例最终导向的会员、单品或组合产品 |
| 成交状态 | 已下单、已付款、成交结果明确，或仅表达意向 |
| 销售节点 | 按聊天实际发生顺序概括，不补写缺失步骤 |

# 5. 阶段一事实分析

## 5.1 十个案例覆盖的业务链路

现有案例共同覆盖以下事实链路：

```text
进入咨询
→ 提供地区、经验、品种或症状
→ 销售追问或判断问题
→ 形成养护、选品或学习需求
→ 介绍会员、商品或组合方案
→ 回应价格、配套、商品形态或物流问题
→ 下单或进入意向阶段
→ 课程、资料、发货和持续指导
```

并非所有案例都覆盖完整链路：

- 案例07止于会员咨询，没有付款或下单记录；
- 案例08未记录成交金额；
- 部分案例没有记录地区、预算、购买渠道或具体环境；
- 部分专业判断依赖照片，但原文没有附带图片内容；
- 案例10的聊天过程经过高度概括，缺少部分逐轮客户原话。

## 5.2 高频事实模式

1. 十个案例全部出现“指导、课程或持续服务”内容。
2. 九个案例明确完成成交，案例07仅形成会员意向。
3. 五个案例完成会员成交，四个案例完成商品或组合商品成交。
4. 病害、错误养护或养护顾虑出现在除案例08外的九个案例中。
5. 不开花或担心不开花出现在案例03、05、06、09。
6. 明确选品行为出现在案例03、08、09、10，案例06还包含品种认知纠正。
7. 明确价格或预算条件集中在商品成交案例03、08、09、10。
8. 成交后的共同动作包括课程、资料、发货和长期指导，但具体动作并不完全一致。

## 5.3 原始信息完整度

## 5.4 后续阶段的事实输入边界

后续能力建模和评测设计可以直接使用：

- 客户原话及其前序对话；
- 文档明确记录的客户背景；
- 当次案例明确记录的商品、价格、权益和成交动作；
- 原案例记录的销售流程顺序。

后续不能未经核验直接作为标准答案的内容包括：

- 地区与品种适配结论；
- 科技苗、病因和用药判断；
- 开花频率、耐寒耐旱等产品特性；
- 会员有效期、包赔条件、活动价格和赠品政策；
- 未展示的照片、订单、库存和实际系统执行结果。

这些内容需要在下一阶段分别标记为“待专业核验”或“待业务规则核验”，再决定是否进入评测参考答案。
